# 룬 트레이스 영상 편집 선정

## 원본 분석

- 원본 길이: 7분 11초
- 원본 해상도: 976×904
- 음성: 전 구간 무음
- 구성: 튜토리얼 → 기본 플로어 → 능력 선택 → 스테이지 보스 → 빌드 확장 → 챕터 보스 → 클리어

## 짧은 영상 선정 기준

- 브라우저 탭과 주소창은 제거한다.
- 성장 선택과 보스 정보는 읽을 수 있도록 정상 속도에 가깝게 유지한다.
- 같은 의미의 반복 경로 입력은 1.25~2배속으로 압축한다.
- 기본 규칙, 능력 성장, 보스 대응, 챕터 클리어가 모두 보이게 한다.
- 원본은 수정하지 않는다.

## 길이별 목적

- 15초: 경로 입력 → 후반 능력 변화 → 챕터 돌파를 한 번에 보여주는 후킹 영상
- 30초: 코어 루프 → 능력 선택 → 보스 정보 → 후반 빌드 → 클리어까지 보여주는 요약 영상
- 1분: 공간 제약과 패배 조건까지 포함해 게임의 규칙과 독창성을 설명하는 메인 시연 영상
- 2분 46초: 실제 플레이 흐름을 더 길게 확인하기 위한 보조 영상

## 산출물 용도

- 15초·30초 MP4: 포트폴리오 첫 화면과 제출 자료의 후킹 영상
- 1분 MP4: 평가자가 코어 루프와 성장·보스 구조를 확인하는 대표 시연 영상
- 15초 GIF: 문서·웹페이지에서 코어 플레이를 빠르게 보여주는 보조 자료

## 광고 사용 기준

- 16:9, 1280×720, 30fps H.264로 출력한다.
- 소리를 끈 자동재생 환경에서도 이해되도록 핵심 규칙을 영상에 직접 표기한다.
- 원본 음성은 전 구간 무음이므로 별도의 음원이나 효과음을 임의로 넣지 않는다.
- 보스 정보는 읽을 시간을 확보하고, 모든 영상은 챕터 클리어 화면에서 종료한다.

## 검수 결과

- 15초: 450프레임, 코어 입력 → 성장 변화 → 최종 타격과 클리어
- 30초: 900프레임, 코어 입력 → 능력 선택 → 보스 정보 → 후반 빌드 → 클리어
- 1분: 1,800프레임, 패배 조건과 공간 제약까지 포함한 전체 구조 설명
- 세 영상 모두 검은 프레임, 브라우저 UI, 재도전 화면 혼입 없음
