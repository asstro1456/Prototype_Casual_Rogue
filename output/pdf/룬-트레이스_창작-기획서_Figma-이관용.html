2. 코어 플레이와 차별점

핵심 문장

한 번의 경로로 적을 베고, 공간을 만들며, 다음 성장을 설계한다.

룬은 몬스터를 처치하고 오염 압박을 줄입니다. 동시에 완성한 경로는 흔적으로 남아 다음 룬의 배치 공간을 줄입니다. 한 번의 입력이 현재 전투와 이후 행동에 모두 영향을 주는 구조입니다.

코어 플레이 루프

룬·이동·오염 예정 확인
→ 경로와 남길 공간 비교
→ 보드에 룬 직접 입력
→ 직접 공격과 능력 처리
→ 몬스터 이동·오염 생성
→ 성장 방향 판단
→ 클리어 또는 실패

한 행동의 판단 구조

판단 확인할 내용 플레이 결과
처치 현재 몇 명을 직접 처리할 수 있는가 EXP와 즉시 안전 확보
공간 다음 룬을 놓을 빈칸이 남는가 이후 행동 가능성 유지
이동 적의 이동 예정 칸을 막거나 이용할 수 있는가 유혹·보스 충돌 조건 형성
성장 능력 발동과 레벨업 조건을 만들 수 있는가 다음 플로어의 공략 방식 변화

핵심 규칙 — 구현 완료

  • 7×7 보드에 플로어마다 제시된 룬 최대 4개를 직접 그립니다.
  • 룬은 직각 회전과 좌우 반전을 허용하며, 입력 경로를 남은 룬과 자동 대조합니다.
  • 경로 위 대상은 직접 공격을 받고 완성된 룬은 흔적으로 남습니다.
  • 일부 몬스터는 이동한 뒤 이전 칸을 오염시킵니다.
  • 흔적과 오염에는 기본적으로 새 룬을 놓거나 기존 경로를 교차할 수 없습니다.
  • 잘못된 룬 입력은 행동으로 소비하지 않습니다.
  • 일반 플로어는 룬 4개를 완성하거나 일반 몬스터를 전부 처치하면 클리어합니다.
  • 보스 플로어는 네 번째 룬 행동까지 보스를 처치해야 합니다.
  • 남은 룬을 하나도 배치할 수 없으면 공간 부족으로 실패합니다.

성공·실패·재진입

상태 판정 다음 흐름
일반 플로어 조기 전멸 남은 룬 수와 관계없이 클리어 보상·레벨업 처리 후 다음 플로어
룬 4개 완성 일반 몬스터가 남아도 일반 플로어 클리어 현재 성장 상태 유지
공간 부족 남은 룬을 하나도 배치할 수 없음 실패 원인 확인 후 플로어 초기화 또는 재도전
보스 생존 네 번째 룬 처리 뒤 보스가 생존 보스전 실패
잘못된 입력 남은 룬과 일치하지 않음 턴을 소비하지 않고 다시 입력
중단 후 복귀 저장된 결과와 무작위 상태 복원 같은 플로어에서 계속 진행

차별점과 게임 필러

차별점 의미
직접 입력 손가락으로 그린 경로가 즉시 공격으로 연결됩니다.
공격이 곧 공간 소모 많이 처치한 경로가 이후 룬의 자리를 막을 수 있습니다.
사전 정보 기반 판단 몬스터 이동과 오염 예정 정보를 보고 경로를 정합니다.
짧은 빌드 변화 한 챕터 안에서 능력이 좋은 경로의 기준을 바꿉니다.

게임 필러는 직접 그리는 직관적인 조작, 한 수에 전투와 공간을 함께 고려, 짧은 세션 안에서 변화하는 능력 빌드입니다.

플레이 감정 흐름

보드와 룬 확인
→ 가능한 경로 발견
→ 더 좋은 위치 탐색
→ 입력 확정
→ 연속 처치 만족
→ 몬스터 이동과 공간 감소
→ 다음 룬에 대한 고민 증가
→ 마지막 룬 성공 또는 공간 부족 실패

공정성 원칙

  • 이동 방향, 오염 예정, 보스 기믹을 행동 전에 공개합니다.
  • 입력 중에 무작위 결과를 다시 설정하지 않습니다.
  • 미리보기와 실제 처리 결과를 일치시킵니다.
  • 강제 종료와 복귀로 같은 결과를 다시 추첨할 수 없게 합니다.
  • 실패 원인은 보드와 결과 화면에서 확인할 수 있어야 합니다.

3. 장르 포지셔닝·타깃·시장 기회

기획 출발점

모바일 퍼즐의 낮은 진입 장벽과 로그라이크의 반복 변화를 결합합니다. 조작은 간단하게 유지하되, 한 플로어의 행동을 4회로 제한하고 능력은 수치보다 경로와 공간 판단을 바꾸게 합니다. 보편적인 HP 대신 보드 공간을 실패 자원으로 사용합니다.

핵심 타깃

복잡한 조작보다 간단히 풀 수 있는 퍼즐을 선호하거나, 한 판만으로 성장과 플레이 변화를 느끼고 싶은 모바일 유저

이용 성향·상황 설계 대응
통학·출퇴근, 쉬는 시간, 취침 전 플레이 플로어 1~3분, 스테이지 5~10분 목표
규칙을 플레이로 익히고 싶음 직접 입력과 즉시 결과, 짧은 튜토리얼
짧아도 선택의 결과를 느끼고 싶음 룬 4회 안에서 처치·공간·성장 비교
실패 이유를 알고 바로 재도전하고 싶음 이동·오염 예고, 실패 원인 표시, 플로어 저장
반복할 이유가 필요함 능력 선택, 룬 조합, 보스 변형

시장 기회 가설

직접 그리는 입력은 일반적인 탭·매치 퍼즐과 다른 첫 인상을 만들 수 있습니다. 경로 입력, 연속 처치, 오염 확산, 공간 부족 실패가 모두 보드에서 표현되므로 광고와 실제 플레이의 행동을 맞추기 쉽습니다.

검증할 가설은 다음과 같습니다.

  • 직접 그리는 조작이 광고와 첫 플레이의 후킹 요소가 되는가
  • 공간 관리가 불쾌한 제한이 아니라 판단의 재미로 인식되는가
  • 짧은 세션 안의 능력 선택이 다음 플레이의 동기가 되는가
  • 광고에서 본 행동과 실제 플레이의 일치가 초기 이탈을 줄이는가

국가별 시장 수치와 수익성 계산은 부록 C. 수치·시장 데이터에서 외부 사실과 내부 해석을 분리해 관리합니다.

4. 첫 플레이·광고·튜토리얼·UX

설계 원칙

광고에서 본 행동을 첫 플레이에서도 바로 수행하게 한다.

첫 1분 안에 룬 확인, 직접 그리기, 적 처리, 흔적 생성을 경험하게 합니다. 광고 소재는 많이 잡았지만 마지막 룬을 놓지 못한 실패, 같은 룬의 서로 다른 결과, 네 개의 룬을 모두 배치하는 도전을 우선 검토합니다.

광고 소재 가설

소재 짧은 전개 전달할 차별점
마지막 룬 공간 남기기 다수를 처치했지만 마지막 룬을 놓지 못한 뒤, 공간을 남긴 경로로 성공 많이 잡는 것이 항상 정답은 아님
같은 룬, 다른 결과 같은 룬을 서로 다른 위치에 배치해 처치·공간·이동 결과 비교 위치와 방향이 결과를 바꿈
네 개의 룬 도전 보드와 룬 4개를 처음부터 보여주고 모두 배치할 수 있는지 질문 짧고 명확한 플로어 목표

광고에서 실패를 과장하기 위해 실제 규칙에 없는 선택을 만들지 않습니다. 소재에서 보여준 입력과 실패 원인을 첫 플레이에서도 그대로 경험하게 합니다.

튜토리얼 흐름 — 확장 계획

단계 경험 전달할 규칙
1 추천 경로를 따라 첫 룬 완성 룬 직접 입력
2 경로 위 몬스터 처치 경로가 공격 범위
3 완성 경로가 흔적으로 유지 공격이 공간을 소모
4 같은 룬의 다른 위치 비교 정답이 하나가 아님
5 이동과 오염 경험 예정 정보 확인
6 마지막 룬 배치 공간 관리와 실패 조건

긴 설명보다 한 번의 플레이 안에서 규칙을 익히게 합니다.

UX 정보 우선순위 — 확정 기획

  1. 처치 예정
  2. 몬스터와 보스의 이동 화살표
  3. 오염 예정

주요 표시 규칙

  • 이동 화살표는 현재 칸과 목적지 칸 사이에 표시합니다.
  • 처치 예정 대상은 알파값을 낮춰 표시합니다.
  • 보스의 방어막, 필요 타격 수, 변형 효과는 진입 시 먼저 공개합니다.
  • 능력은 평소 아이콘으로 유지하고 클릭 또는 호버로 상세 설명을 엽니다.
  • 레벨업 선택은 가장 높은 우선순위의 모달로 표시합니다.
  • 모달을 감춘 뒤 화면을 클릭하면 능력 선택을 다시 확인할 수 있어야 합니다.
  • QA 패널은 보드를 가리지 않는 게임 화면 밖에 배치합니다.
  • 핵심 상태는 크기·굵기·아이콘을 함께 사용하고 색상만으로 구분하지 않습니다.

텍스트 가독성

  • 플레이 필수 정보는 보조 설명보다 크게 표시합니다.
  • 제목과 핵심 수치는 본문보다 굵게 표시합니다.
  • 발동 조건, 수치, 상태 변화만 선택적으로 강조합니다.
  • 핵심 설명은 한 문장, 최대 두 줄을 기준으로 검토합니다.
  • 구체적인 글자 크기와 세션 기준은 부록에서 관리합니다.

첫 플레이 확인 지표

첫 행동 시간, 첫 룬 입력 성공률, 잘못된 입력 횟수, 첫 플로어 진입·클리어율, 튜토리얼 이탈률, 이동·오염 예고 이해도를 확인합니다.

5. 세션·성장·반복 구조

세션 구조

단위 구성 목표 시간 역할
플로어 룬 최대 4회 약 1~3분 짧은 문제 상황
스테이지 3개 플로어 약 5~10분 성장 최소치와 판단 숙련 확인
챕터 3개 스테이지 약 15~30분 하나의 빌드 완성

현재 시간은 실측이 아닌 목표값입니다. 플로어 단위로 저장하고, 같은 무작위 결과로 복원해 짧은 단위의 플레이와 종료 악용 방지를 함께 처리합니다.

챕터 내부 성장

플로어 진입
→ 직접 처치 EXP 획득
→ 레벨업 능력 선택
→ 스테이지 보스 공략
→ 다음 스테이지 진입
→ 챕터 보스 공략
→ 능력·레벨·EXP 초기화

성장 규칙 — 구현 완료

  • 직접 경로로 일반 몬스터를 처치하면 EXP 1을 획득합니다.
  • 능력의 추가 처치는 EXP를 지급하거나 다른 능력을 연쇄 발동시키지 않습니다.
  • 레벨업 요구치는 챕터 안에서 증가하지 않습니다.
  • 레벨업 시 최대 3장의 능력 카드를 같은 확률로 제시합니다.
  • 최대 단계 능력은 후보에서 제외하고 선택 능력은 챕터 동안 유지합니다.
  • 모든 성장이 끝난 뒤의 보상은 아웃게임 재화로 전환하는 방향을 검토합니다.

아웃게임과 반복 — 확장 계획

  • 능력·레벨·EXP는 챕터 단위로 초기화합니다.
  • 아웃게임 재화와 획득한 외형은 유지합니다.
  • 도구 확보와 외형 해금을 장기 보상으로 검토합니다.
  • 범용 인게임 특수 자원은 도입하지 않습니다.
  • 반복 변화는 룬 순서, 몬스터 이동, 능력 선택, 보스 변형에서 만듭니다.
  • 메타 시스템이 핵심 퍼즐보다 앞서지 않게 합니다.

반복 동기

현재 반복 동기는 룬 조합과 순서, 몬스터 배치와 이동, 능력 선택지, 보스 변형, 실패 후 다른 경로 시도에서 만듭니다. 제품화 이후에는 능력·룬 도감, 도전 과제, 최고 기록, 외형 수집, 일일·주간 도전을 검토합니다.

플레이어가 실패한 빌드를 챕터 시작부터 다시 구성할 수 있도록 챕터 단위 초기화를 유지합니다. 이전 선택이 지나치게 누적되어 되돌릴 수 없는 구조는 피합니다.

6. 능력·빌드·전략 다양성

설계 목표

능력은 수치 상승에 그치지 않고, 경로 선택과 공간 운용 방식을 바꾼다.

전투 능력은 추가 처치와 공간 확보를 돕고, 퍼즐 능력은 직접 경로와 배치 가능성을 안정화합니다. 순수 전투, 순수 퍼즐, 혼합 빌드를 모두 허용하되 한 행동에서 같은 대상은 최대 1회만 피격됩니다.

능력 구성 — 구현 완료

능력 분류 최대 단계 핵심 효과
유혹 전투 3 새 룬에 이동이 막힌 일반 몬스터를 룬으로 충돌시킴
도탄 전투 3 일반 몬스터 2체 이상 직접 처치 시 가까운 대상을 추가 공격
끝점 참격 전투 3 룬의 마지막 진행 방향과 끝점 주변을 추가 공격
오염 무시 퍼즐 1 플로어당 한 번 오염 칸 1개를 통과
룬 연결 퍼즐 1 기존 룬 끝점에서 새 룬을 잇고 이전 흔적을 제거
룬 교체 퍼즐 1 플로어당 한 번 남은 룬 하나를 다른 기본 형태로 교체

전투 능력의 개성

능력 발동 기준 성장 방향 미리보기
유혹 새 룬이 생존 대상의 이동 목적지를 막음 처리 대상 1체 → 2체 → 조건을 만족한 전체 충돌 대상의 알파값을 낮춤
도탄 한 룬으로 일반 몬스터 2체 이상 직접 처치 추가 공격 수와 발동 기회 강화 끝점에서 가까운 추가 대상 표시
끝점 참격 룬 끝점과 마지막 진행 방향 확정 추가 1칸 → 총 3칸 → 끝점을 둘러싼 총 7칸 입력 중 공격 범위와 처치 대상 표시

유혹의 동률 우선순위는 화면 기준 왼쪽, 그다음 위쪽을 먼저 사용합니다. 도탄은 끝점과 가까운 대상을 고르고 동률이면 왼쪽 위를 우선합니다. 우선순위는 같은 상태에서 결과를 다시 추첨하지 않기 위한 규칙입니다.

퍼즐 능력의 개성

  • 오염 무시는 플로어당 한 번 오염 칸 하나를 경로에 포함하되 해당 칸에 흔적을 남기지 않습니다.
  • 룬 연결은 기존 흔적 끝점에서 새 룬을 시작하고 완성 시 연결에 사용한 이전 흔적을 제거합니다.
  • 룬 교체는 플로어당 한 번 남은 룬을 다른 기본 형태로 무작위 교체합니다.

퍼즐 능력은 현재 성장 단계가 없는 임시 구조입니다. 전투 능력과의 체감 격차를 확인한 뒤 단계 확장을 결정합니다.

처리 순서와 미리보기

직접 공격
→ 끝점 참격
→ 유혹
→ 도탄
→ 생존 몬스터와 보스 이동
→ 오염 처리

룬이 확정되기 전까지 직접 처치와 능력 추가 처치 대상을 낮은 투명도로 표시합니다. 능력으로 추가 처치한 대상은 다른 능력을 연쇄 발동시키지 않으며 직접 처치 EXP도 지급하지 않습니다.

빌드 방향

빌드 중심 능력 달라지는 판단
공격 확장 도탄·끝점 참격 한 룬의 직접 처치 수와 추가 공격 범위
이동 예측·충돌 유혹 생존 대상의 이동 예정 칸을 막는 위치

다양성 확인 기준

  • 능력에 따라 좋은 경로의 기준이 바뀌는가
  • 서로 다른 능력이 같은 결과만 만들지는 않는가
  • 특정 능력 없이도 보스를 공략할 수 있는가
  • 능력 조합이 플레이어의 판단을 무의미하게 만들지는 않는가
  • 한 가지 조합만 반복해서 선택하지는 않는가
  • 선택 결과를 다음 플로어에서 바로 체감하는가

7. 보스 시스템

역할

보스는 현재 빌드가 필요한 성장 최소치를 채웠는지 확인하는 관문이다.

각 스테이지의 세 번째 플로어에 이동형 보스를 배치합니다. 스테이지 1·2는 가벼운 관문이며, 스테이지 3은 완성된 빌드와 퍼즐 판단을 확인합니다.

기본 규칙 — 구현 완료

  • 모든 몬스터의 본체는 방어막이 없을 때 1회 피격으로 처치됩니다.
  • 보스는 일반 몬스터보다 먼저 이동 칸을 예약하고 행동 전에 방향을 공개합니다.
  • 한 룬 행동에서 보스는 최대 1회만 피해를 받습니다.
  • 네 번째 룬까지 보스를 처치하지 못하면 실패합니다.
  • 스테이지별 방어막과 동반 몬스터 수는 부록의 초기 밸런스값을 따릅니다.

기본 기믹

기믹 조건 결과
돌진 충돌 새 룬이 보스의 예약 이동 칸을 막음 해당 행동에서 미피격 상태면 1회 피격 후 정지
탈출 이동 보스가 흔적·오염·몬스터에 완전히 갇힘 우선순위에 따라 장애물 하나를 제거하고 이동

탈출 자체는 피해를 주지 않으며, 보스가 영구적으로 갇혀 층 초기화를 강제하는 상황을 막습니다.

보스 타격 수단

수단 플레이어 판단 제한
직접 경로 보스가 있는 칸을 룬으로 통과 한 행동 최대 1피격
돌진 충돌 예약 이동 칸을 새 룬으로 선점 이미 피격됐다면 추가 피해 없음
약점 표식 보스 대신 공개된 표식을 경로에 포함 해당 변형에서만 사용
수호 연결 연결된 일반 몬스터를 우선 처치 연결 대상과 결과를 행동 전에 표시

보스는 일반 몬스터와 달리 여러 번의 타격 기회를 요구합니다. 직접 경로만 강제하면 네 번의 룬 안에서 선택지가 지나치게 줄어들기 때문에, 공간 퍼즐과 동반 몬스터를 이용한 보조 타격 수단을 함께 제공합니다.

보스 변형 — 구현 완료·검증 필요

스테이지 변형 핵심 효과
1 약점 표식 표식을 룬 경로가 직접 통과하면 보스 피격
2 수호 연결 연결된 일반 몬스터를 처치하면 보스 피격
3 증원 소환 보스가 피격 후 생존하면 인접 칸에 일반 몬스터 1체 소환

현재는 이해도와 난도를 분리해 확인하기 위해 스테이지별로 고정합니다.

보스 정보 표시

  • 스테이지와 보스 플로어 진입 시 방어막, 필요 타격 수, 변형 효과를 먼저 보여줍니다.
  • 플레이 중에는 상단에서 변형 이름과 핵심 효과를 다시 확인할 수 있습니다.
  • 방어막은 굵은 하늘색 외곽선과 반투명 패널로 표시합니다.
  • 예약 이동, 약점, 수호 연결, 소환 위치는 행동 전에 표시합니다.

공정성과 확인 지표

  • 스테이지 진입 시 방어막, 필요 타격 수, 변형 효과를 공개합니다.
  • 특정 능력이나 구매형 도구를 필수로 요구하지 않습니다.
  • 같은 상태에서 결과를 다시 추첨할 수 없게 합니다.
  • 변형별 클리어·포기·재시도, 보스 피격 출처, 평균 필요 타격 수, 기믹 이해도, 탈출 이동 빈도를 확인합니다.

8. 도구·콘텐츠 확장·수익화 가설

도구 원칙

  • 정상적인 퍼즐은 도구 없이도 해결할 수 있어야 합니다.
  • 도구는 의도적인 불편의 해결책이 아니라 귀찮음이나 단발성 실패를 보완합니다.
  • 능력은 챕터 동안 반복 사용하는 약한 변화, 도구는 사용 시 소모되는 강한 보완으로 구분합니다.
  • 도구는 세 종류만 유지합니다.
도구 역할 소비 시점
탐색 렌즈 최대 처치 룬과 경로를 최대 3개까지 안내. 처치 수가 0이면 합법 경로 표시 안내 경로를 완성했을 때
교차 인장 다음 룬 하나가 기존 흔적 1칸을 통과 실제 교차한 룬을 완성했을 때
정화 도구 선택한 오염 칸 1개를 즉시 제거 효과 적용 즉시

탐색 렌즈는 현재 보드에서 가장 많은 몬스터를 처리할 수 있는 룬을 강조합니다. 동률이면 여러 룬을 표시하고, 룬을 선택하면 가능한 최대 처리 경로를 최대 3개까지 보여줍니다. 선택 룬을 바꾸면 경로도 즉시 바뀝니다. 최대 처치 수가 0이면 합법적인 경로를 안내합니다.

렌즈 사용 중에는 보드와 룬을 딤드 화면 위에서 강조합니다. 경로대로 룬을 완성해야 도구와 턴을 소비하며, 안내만 확인하고 이탈하는 사용은 허용하지 않는 방향입니다. 이 제약이 불쾌한지는 별도로 확인합니다.

교차 인장은 흔적 여러 칸을 따라가거나 오염을 통과할 수 없습니다. 정화 도구는 몬스터, 보스, 흔적이 아니라 오염 칸 하나만 대상으로 합니다.

반입 수량, 중복 제한, 가격, 무료 공급량, 재시작 시 환불 규칙은 미정입니다.

콘텐츠 생산 구조

룬 세트 × 몬스터 구성 × 보드 조건 × 능력 풀 × 보스 변형 × 특수 규칙

확장 요소 변화하는 판단
룬·보드 배치 가능 위치와 공간 활용
몬스터·보스 처치 우선순위와 공략 목표
능력 공격·경로·이동 제어 방식
목표·특수 규칙 플로어의 성공 기준

보드는 최대 9×9, 일반 룬은 4~6칸, 특수 룬은 최대 7칸까지 검토합니다. 보드 확대보다 몬스터·보스·특수 칸의 판단 밀도를 먼저 조정합니다.

수익화·운영 원칙 — 검증 가설

  • 진행도나 핵심 판단을 결제로 제거하지 않습니다.
  • 실패 직후 광고를 반복 노출하지 않고 보상은 선택적으로 제안합니다.
  • 유료 도구 없이 해결할 수 없는 보드를 허용하지 않습니다.
  • 광고 제거, 선택형 보상 광고, 도구 묶음, 보드·룬·UI·배경 외형을 후보로 둡니다.
  • 배치 횟수 추가, 능력 영구 적용, 챕터 스킵은 제외합니다.
  • 일일·주간 특수 규칙과 시즌 외형은 코어 재미 검증 이후 검토합니다.

현재 단계에서는 매출 가능성보다 도구 의존, 광고 이후 이탈, 불공정 인식이 증가하지 않는지를 먼저 확인합니다.

9. 프로토타입 변천과 개선 근거

개선 원칙

초기 아이디어를 유지하는 것보다 유저가 실제로 판단할 수 있는 재미를 남긴다.

수정 흐름

단계 확인한 문제 판단과 반영
인접 블록 제거형 항상 다수를 타격하는 것이 유리해 전략이 고정됨 공격에도 이후 행동의 비용이 필요해 흔적과 공간 부족 실패 도입
실시간 디펜스 실시간 압박이 경로 판단을 방해함 생각할 시간을 보장하도록 턴제 이동과 방향 사전 공개
룬 트레이스 초기형 오염이 공개된 이동 정보를 보고 세운 계획을 무효화함 오염 대상 공개, 행동당 대상 제한, 플로어당 상한 적용
이동형 보스 반복 타격 수단이 적고 보스가 갇힘 돌진 충돌, 탈출 이동, 약점·수호 변형 추가

대표 개선 사례

문제 수정 확인할 결과
오염이 빠르게 늘어 다음 수를 무효화 행동당 대상과 플로어 총량 제한, 예정 칸 공개, 실제 이동 시에만 생성 공간 부족 실패가 갑작스럽지 않은가
화살표가 몬스터 내부 상태와 겹침 현재 칸과 이동 칸 사이에 배치 방향과 상태를 동시에 읽을 수 있는가
보스를 네 룬 안에 반복 타격하기 어렵고 갇힘 돌진 충돌, 탈출 이동, 약점 표식, 수호 연결 능력 강제 없이 타격 기회를 만들 수 있는가

사례 1. 오염 칸 수 과다

몬스터의 동선은 예측할 수 있었지만 오염이 빠르게 늘어 다음 수의 계획을 무효화했습니다. 행동당 오염 대상과 플로어당 총량을 제한하고, 대상과 예정 칸을 미리 표시했습니다. 실제 이동에 성공한 몬스터만 이전 칸을 오염시키며 취소된 역할은 같은 턴의 다른 몬스터에게 재배정하지 않습니다.

확인할 것은 오염이 사라졌는지가 아닙니다. 이동 예고로 세운 계획이 실제 결과와 이어지면서도 공간 압박이 유지되는지를 봅니다.

사례 2. 몬스터 이동 화살표

화살표를 몬스터 내부에 넣으면 적의 상태와 이동 정보가 겹쳤습니다. 현재 칸과 목적지 칸 사이로 이동해 두 정보를 분리했습니다. 이후 옵션에서 크기와 표시 여부를 조절할 수 있는 구조를 검토합니다.

사례 3. 보스 타격과 갇힘

일반 몬스터는 남아도 클리어를 막지 않지만 보스는 네 번의 룬 안에서 반복 타격해야 했습니다. 직접 경로만으로는 타격 수단이 부족했고, 보스가 흔적과 오염에 갇히면 정상 진행도 막혔습니다.

돌진 충돌과 변형별 보조 타격 수단을 추가하고, 완전히 갇힌 보스는 주변 장애물 하나를 제거해 이동하도록 했습니다. 보스의 난도를 높이는 것보다 해결 가능한 타격 기회를 만드는 것이 우선입니다.

10. 검증 계획과 데이터

검증 순서

시장성과 재미가 확인됐다고 단정하지 않습니다. 코어 조작, 게임 구조, 초기 유지, 상업성 순서로 검증합니다.

단계 핵심 질문 주요 지표
코어 조작 직접 그리기를 빠르게 이해하고 정확히 입력하는가 첫 행동 시간, 입력 성공률, 오입력, 회전·반전 성공률
게임 구조 공간 판단과 능력·보스가 재도전을 만드는가 플로어·세션 클리어, 실패 원인, 재시도, 능력 선택, 보스 포기
초기 유지 짧은 세션이 복귀와 반복으로 이어지는가 첫 스테이지 완료, 조기 이탈, D1·D7, 챕터 복귀
상업성 획득·광고·도구가 코어 경험을 훼손하지 않는가 소재별 전환, 광고비 회수, 광고·도구 사용 후 이탈·클리어

상업 지표는 코어 조작과 초기 유지가 확인된 뒤 판단합니다.

단계별 세부 항목

1단계. 코어 조작

  • 첫 행동까지 걸린 시간
  • 첫 룬 입력 성공률과 잘못된 입력 횟수
  • 회전·반전 형태 입력 성공률
  • 드래그 조작 만족도
  • 미리보기와 실제 결과의 불일치

2단계. 게임 구조

  • 플로어 첫 시도와 세션 내 최종 클리어율
  • 공간 부족·보스 생존 실패 비중
  • 실패 후 단기 재시도와 실패 직후 이탈
  • 능력 선택 분포와 직접·추가 처치 차이
  • 스테이지 플레이 시간 분포
  • 중단 후 복원 성공률

3단계. 초기 유지

  • 첫 플로어 진입과 첫 스테이지 완료
  • 최초 세션 조기 이탈
  • D1·D7 잔존율과 일일 세션 수
  • 챕터 중단 후 복귀

4단계. 상업성

  • 광고 소재별 클릭과 설치 전환
  • 설치당 비용과 광고비 회수
  • 보상형 광고 선택·완료와 노출 후 이탈
  • 도구 사용 가능 상황 대비 사용률
  • 도구 사용 후 같은 시도 클리어
  • 결제 노출 후 이탈·환불·불공정 응답

데이터 수집과 현재 로그

직접 플레이, 예외 사례 조사, 자동 플레이 로그, QA 지원 기능, 외부 플레이테스트 관찰, 인터뷰를 함께 사용합니다.

현재 로그에는 세션·복귀, 스테이지·플로어, 룬 경로 결과, 직접·능력 처치, 보스 변형·피격, 실패 원인, 능력 선택, 저장 복원을 포함합니다.

판정 원칙

  • 공개 벤치마크가 없는 클리어율과 도구 사용률을 업계 표준처럼 만들지 않습니다.
  • 국가, 장르, 플랫폼, 기간이 다른 수치를 하나의 기준값으로 합치지 않습니다.
  • 소규모 테스트는 방향 확인에 사용하고 수익성 확정 근거로 사용하지 않습니다.
  • 평균뿐 아니라 중앙값과 상위 구간을 함께 확인합니다.

12. 조건부 제품화·리스크·결론

제품화 전제

현재 목표는 1인 출시가 아닙니다. 코어 조작과 시장 가능성을 보여주는 포트폴리오 프로토타입이며, 제품화는 팀 또는 퍼블리셔 협업을 전제로 합니다.

단계 목표 결과물 진행 조건
M1~M2 모바일 UI·터치, 튜토리얼, 로그 보완 핵심 규칙과 첫 행동·실패 흐름 검수
M3~M4 Android 테스트 빌드와 폐쇄형 플레이테스트 저장·복원·로그 수집 안정화
M5 코어 규칙과 밸런스 조정 클리어·실패·재시도 데이터 확보
M6~M7 비주얼·사운드 개선과 광고 소재 검증 코어 재미와 첫 플레이 이해도 유지
M8~M9 소프트론칭, 확장 또는 방향 전환 판단 유지·획득·수익 가드레일 충족

메타게임과 장기 운영은 코어 검증 이후 설계합니다.

주요 리스크

결론

룬 트레이스는 직접 그리는 입력이 전투와 공간 관리에 동시에 적용되고, 룬·몬스터·능력·보스 규칙의 조합으로 반복 가능한 콘텐츠를 만드는 모바일 캐주얼 퍼즐 로그라이크입니다.

현재 프로토타입은 완성된 사업성을 주장하지 않습니다. 직접 입력, 공간 관리, 짧은 능력 성장이 실제 재미와 시장 지표로 이어질 가능성을 확인하고, 불쾌하거나 막히는 지점을 규칙·정보 표시·예외 처리로 수정해 다시 검증할 수 있는 구조를 만든 결과물입니다.

부록 C. 수치·시장 데이터

본문에는 플레이 구조와 판단 방향을 우선 배치합니다. 초기 밸런스값, 확장 계산, 시장 근거, 수익성 시나리오는 이 부록에서 관리합니다. 구현값과 목표값, 외부 사실과 내부 가정을 구분합니다.

세션 시간은 외부 시장 평균을 그대로 복사한 값이 아닙니다. 학생의 쉬는 시간과 모바일의 짧은 플레이 상황을 가정한 내부 목표입니다. 실제 판단은 평균보다 P50과 P90을 함께 사용합니다.

P50은 전체 기록의 중앙값이며, P90은 기록의 90%가 해당 시간 안에 들어오는지를 확인하는 기준입니다.

C-4. 보드와 룬 확장 계산

기존 흔적과 겹치지 않는 기본 규칙을 기준으로 계산합니다.

보드 전체 칸 8칸 룬 1개 8칸 룬 4개
7×7 49칸 8칸·16.3% 32칸·65.3%
9×9 81칸 8칸·9.9% 32칸·39.5%

7×7에서 8칸 룬 4개는 보드의 약 3분의 2를 차지합니다. 몬스터와 오염 공간까지 고려하면 배치 선택보다 공간 부족이 먼저 발생할 가능성이 큽니다. 8칸 룬은 기본 확장 범위에서 제외하고, 9×9에서도 별도 검증이 필요한 대형 룬으로만 취급합니다.

C-8. 수익성 시나리오 참고

다음 값은 매출 예측이 아니라 팀 규모와 유료 유입 위험을 비교하기 위한 내부 민감도입니다.

ARPU는 이용자 1명당 평균 수익을 뜻합니다. IAP는 인앱 구매, IAA는 인앱 광고 수익을 뜻합니다.

시나리오 D90 IAP ARPU D90 IAA ARPU 설치당 D90 순기여금
보수 $0.10 $0.20 약 385원
기준 $0.35 $0.45 약 1,009원
공개 평균 합산 상단 $1.34 $0.55 약 2,280원

계산에는 인앱 구매 수수료 15%, 결제·분석·지원 변동비 준비율 10%, 계획환율 1달러당 1,500원을 적용했습니다. 세금, 환불, 고정비, 유료 유입비는 포함하지 않았습니다. IAP와 IAA 공개값이 동일한 하이브리드 코호트라는 보장이 없으므로 상단값을 일반 목표로 사용하지 않습니다.

유료 유입비를 제외한 계산입니다. 결론은 높은 수익을 예상한다는 것이 아닙니다. 작은 팀, 높은 유기적 유입 비중, 검증된 광고 생애가치가 갖춰질 때 조건부로 제품화를 검토할 수 있다는 뜻입니다.
