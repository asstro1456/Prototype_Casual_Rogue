# 룬 트레이스 — 프로토타입

현재 표시 버전은 `v0.0.6 · RUNE TRACE`다.

## 핵심 규칙

- 한 층마다 무작위 룬 4개가 판 왼쪽에 제시된다.
- 별도 선택 없이 목록에 있는 룬을 그리면 자동으로 인식된다.
- 룬은 회전하거나 좌우 반전해서 그려도 된다.
- 대각선 룬은 포인터가 중간의 가로·세로 칸을 스치더라도 대각선 방향을 우선한다.
- 완성된 경로 위의 적은 제거된다.
- 제거한 적 1체마다 EXP 1을 얻고 다음 층까지 누적된다.
- EXP 3마다 레벨이 오르고 `능력 1·2·3` 중 하나를 더미로 획득한다.
- 살아남은 적은 이동한 뒤 빈 칸을 오염시킨다.
- 적을 전부 제거하지 않아도 룬 4개를 완성하면 층을 통과한다.
- 남은 룬을 놓을 공간이 하나도 없으면 실패한다.
- `한 수 되돌리기`는 마지막 룬을 그리기 전 상태로 복원한다.
- `층 초기화`는 현재 층의 최초 배치로 돌아간다.

외부 이미지·폰트·라이브러리 없이 `index.html`만 열어 실행할 수 있다.
