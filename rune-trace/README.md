# 룬 트레이스 — 프로토타입

현재 표시 버전은 `v0.2.3 · RUNE TRACE`다.

## 핵심 규칙

- 한 층마다 무작위 룬 4개가 판 왼쪽에 제시된다.
- 별도 선택 없이 목록에 있는 룬을 그리면 자동으로 인식된다.
- 룬은 회전하거나 좌우 반전해서 그려도 된다.
- 대각선 룬은 포인터가 중간의 가로·세로 칸을 스치더라도 대각선 방향을 우선한다.
- 모든 대상은 방어막이 남아 있으면 피격 시 방어막 1개를 잃고, 방어막이 없으면 본체가 처치된다.
- 룬 경로가 방어막 없는 본체를 직접 처치했을 때만 EXP 1을 얻고 다음 층까지 누적된다.
- 한 챕터는 3스테이지, 한 스테이지는 3플로어로 진행한다.
- EXP 7마다 레벨이 오르고 전투 능력 `유혹`, `도탄`, `끝점 참격`과 퍼즐 능력 `오염 무시`, `룬 연결`, `룬 교체` 중 최대 3개가 같은 확률의 선택지로 나온다.
- 전투 능력은 최대 3단계, 퍼즐 능력은 현재 최대 1단계이며 최대 단계 능력은 선택지에서 제외한다.
- 레벨업 모달을 감춰 보드를 확인할 수 있지만, 능력을 선택하기 전에는 다음 턴으로 진행할 수 없다.
- 남은 룬과 보유 능력은 왼쪽의 분리된 구역에 표시하며, 능력 아이콘을 누르면 현재 단계·효과·사용 상태를 확인할 수 있다.
- 보드 하단에는 `탐색 렌즈`, `교차 인장`, `정화 도구` 슬롯을 표시한다. 현행 기획에 획득량과 실제 효과가 없어 수량은 0으로 시작한다.
- `한 수 되돌리기`, 플로어 초기화, 도구·능력 추가, 레벨업 발생, 룬 리롤과 플레이 데이터 초기화는 게임 카드 바깥의 오른쪽 `QA 전용` 패널에서 제공한다.
- 서로 다른 능력을 함께 보유할 수 있으며 직접 공격 → 끝점 참격 → 유혹 → 도탄 순서로 복합 처리한다.
- 새 룬을 확정하기 전에 직접 처치와 능력 추가 처치 대상을 낮은 투명도로 미리 표시한다.
- 룬 경로의 직접 처치만 EXP를 주며, 능력으로 추가 처치한 적은 플로어 섬멸 수에만 포함한다.
- `유혹`은 새 룬에 이동 목적지가 막힌 생존 적을 우선순위에 따라 추가 처치한다.
- `도탄`은 한 룬으로 일반 적 2체 이상을 직접 처치했을 때 플로어당 한 번, 끝점과 가까운 일반 적을 추가 피격한다.
- `끝점 참격`은 룬 끝점의 진행 방향에 단계별 추가 공격 범위를 만든다.
- `오염 무시`는 플로어당 한 번 오염 칸 하나를 경로에 포함하되 그 칸에는 흔적을 남기지 않는다.
- `룬 연결`은 기존 흔적의 끝점에서 새 룬을 이어 그리고 완성 시 이전 흔적을 제거한다.
- `룬 교체`는 플로어당 한 번 남은 룬 하나를 다른 기본 형태로 고정 교체한다.
- 별도 도구나 능력 없이 새 룬 선이 기존 룬 선을 교차해 통과할 수 없다.
- 최초 동의 시 익명 참가자·세션 ID로 플레이 이벤트를 자동 기록한다.
- 이벤트는 IndexedDB에 먼저 보관하고 20개 누적, 30초 경과 또는 주요 종료 시점에 Google Apps Script로 배치 전송한다.
- 서버는 같은 세션·플로어 문맥의 이벤트를 압축 원본 한 행에 묶고 참가자·세션·플로어·대시보드용 집계 시트를 증분 갱신한다.
- 마지막 사용자 입력 후 5분이 지나면 자동 전송을 멈추며, 다음 입력에서 로컬 대기 이벤트 전송을 재개한다.
- 탭을 닫은 뒤 5분 안에 재접속하면 같은 세션으로 이어서 누적하고, 5분을 넘기면 이전 세션을 중간 이탈로 확정한 뒤 저장 데이터 초기화 여부를 묻는다.
- 전송 실패 이벤트는 로컬에 유지하고 재실행·온라인 복귀 시 다시 전송한다.
- 이동 가능한 일반 몬스터 중 턴마다 최대 2체만 보라색 오염 예정 대상으로 표시되고, 실제 이동에 성공하면 떠난 원래 칸을 오염시킨다.
- 몬스터가 생성하는 오염은 플로어당 누적 6칸이 상한이며 처치되거나 이동이 막힌 대상의 오염은 다른 몬스터에게 재배정되지 않는다.
- 이동형 보스는 기본 오염을 만들지 않고, 소환 몬스터는 등장 다음 턴부터 오염 후보가 된다.
- 이동할 수 없는 적은 자물쇠 이미지로 정지 의도를 표시한다.
- 각 스테이지 3번째 플로어에는 이동형 보스와 일반 몬스터가 등장하며, 보스를 처치하면 즉시 클리어한다.
- 보스는 스테이지 1·2에서 방어막 1개, 스테이지 3에서 2개를 기본으로 보유하고 `증폭 방어막` 또는 `증원 소환` 변형 하나가 적용된다.
- 스테이지 진입과 보스 플로어 진입 때 보스 정보를 보여주며 헤더의 보스 정보 버튼으로 다시 열 수 있다.
- 상단에 현재 보스 변형 이름과 핵심 효과를 계속 표시하고, 방어막이 남은 보스에는 굵은 하늘색 외곽선과 반투명 패널을 표시한다.
- 챕터 마지막 플로어가 끝나면 대기 중인 레벨업 선택을 생략한다.
- 스테이지 1·2에서는 스테이지 시작 성장 상태로 돌아가는 `스테이지 재도전`을 제공한다.
- `챕터 재도전`은 스테이지 3의 마지막 플로어를 완료한 뒤에만 제공한다.
- 일반 플로어는 적을 모두 제거하거나 룬 4개를 완성하면 통과한다.
- 보스 플로어는 네 번째 룬 처리 뒤에도 보스가 살아 있으면 실패한다.
- 남은 룬을 놓을 공간이 하나도 없으면 실패한다.
- `한 수 되돌리기`는 마지막 룬을 그리기 전 상태로 복원한다.
- `층 초기화`는 현재 층의 최초 배치로 돌아간다.
- 정상 룬 완성, 능력 선택, 룬 교체 뒤 현재 진행 상태를 브라우저에 저장하고 재접속 시 같은 무작위 결과로 복원한다.

외부 라이브러리 없이 실행할 수 있다. 실제 로그 전송 테스트는 Apps Script 웹앱 URL 설정과 HTTPS 배포가 필요하며, 설정 방법은 `docs/play-log-setup.md`에 기록했다.
