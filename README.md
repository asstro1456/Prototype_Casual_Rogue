# 룬 트레이스 — 프로토타입 허브

루트의 `index.html`을 열면 각 전투 시스템을 선택할 수 있다.

## 프로토타입

- `rune-trace/` — 현재 개발 중인 룬 경로 퍼즐 `v1.0.0`
- `archive/clear-all-v0.1.0/` — 전체 제거 퍼즐 보관판 `v0.1.0`
- `archive/realtime-defense-v0.4.0/` — 실시간 디펜스 보관판 `v0.4.0`

각 폴더는 외부 라이브러리 없이 독립적으로 실행된다.

## 개발 및 AI 활용

게임의 핵심 규칙, 시스템 구조, 밸런스, UI 요구사항, 예외 처리,
QA 기준 및 최종 구현 방향은 저장소 소유자가 기획하고 결정했습니다.

HTML, CSS, JavaScript 구현 과정에는 생성형 AI 도구를 활용했습니다.
생성된 코드는 저장소 소유자의 지시에 따라 검수·수정·통합했습니다.
