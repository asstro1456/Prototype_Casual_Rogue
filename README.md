# 프리즘 리콜 — 실시간 디펜스 프로토타입

`index.html`을 브라우저로 열면 바로 실행된다. 외부 이미지·폰트·라이브러리를 사용하지 않는다.

현재 표시 버전은 `v0.4.0 · REALTIME DEFENSE`다. 헤더 왼쪽과 모든 모달 오른쪽 위에 같은 버전을 표시하며, 이후 개발에서는 `app.js`의 버전 상수와 `index.html`의 CSS·JavaScript 캐시 버전을 함께 갱신한다.

## 구현 범위

- 고정 웨이브 4라운드
- 5열×5거리 전투선에서 적의 자동 등장과 실시간 전진
- 가장 가까운 적 최대 2체를 공격하는 전사 자동 전투
- 중장형을 우선 저격하는 궁수 자동 전투
- 적색·청색·황색 중 하나를 탭해 화면의 같은 색 적 전체에 1피해
- 세 색이 공유하는 1.8초 공격 쿨타임
- 일반형 1HP·중장형 2HP 적 2종
- 런 공용 보호막과 최하단 돌파 피해
- 도움말을 여는 동안 전투 일시정지
- R4 결과 및 재시작

## 의도적으로 제외한 범위

- 실제 캐릭터·몬스터 리소스
- 전투 애니메이션과 사운드
- 공격 위치 직접 선택과 두 번 탭 조작
- 전사·궁수의 수동 조작
- 연계 게이지와 능력 선택
- 적별 이동 속도와 돌파 피해 차이
- 8·12라운드 전체 런
- 영구 성장·재화·BM
- 서버 저장과 계정
- 정식 밸런스 수치

## 현재 더미 데이터

- 라운드 웨이브: `app.js`의 `ROUND_DATA`
- 색상 정보: `app.js`의 `COLOR_META`
- 적 유형: `app.js`의 `ENEMY_TYPE_META`
- 이동·등장·자동 공격·쿨타임 간격: `app.js` 상단의 시간 상수

상세 구현 규칙과 변경 내역은 `docs/Project_TTT_저격_포트폴리오_설계안.md`를 기준으로 한다.
