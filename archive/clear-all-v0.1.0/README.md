# 프리즘 리콜 — 듀오 전투 프로토타입

`index.html`을 브라우저로 열면 바로 실행된다. 외부 이미지·폰트·라이브러리를 사용하지 않는다.

현재 표시 버전은 `v0.1.0 · DUO COMBAT`이다. 헤더 왼쪽과 모든 모달 오른쪽 위에 같은 버전을 표시하며, 이후 개발에서는 `app.js`의 버전 상수와 `index.html`의 CSS·JavaScript 캐시 버전을 함께 갱신한다.

## 구현 범위

- 4라운드 블록
- 공격 위치가 표시된 행동 후보 3개 중 하나를 탭하는 단일 조작
- 근접 캐릭터의 연결 덩어리 표면 제거
- 궁수의 단일 결정 다층 관통
- 근접·궁수 교대 사용으로 충전하는 연계 공격
- 다층 결정과 반격 게이지
- 연계 게이지와 합동 공격 후보
- 런 공용 보호막
- R1·R3 종료 후 능력 3택
- 회전 베기·관통 화살·교차 사격
- R4 결과 및 재시작
- 시작 보호막 3칸
- R1·R2 반격 6탭, R3·R4 반격 5탭
- 마무리 탭으로 모든 결정을 제거하면 반격 취소

## 의도적으로 제외한 범위

- 실제 캐릭터·몬스터 리소스
- 전투 애니메이션과 사운드
- 공격 위치 직접 선택과 두 번 탭 조작
- 8·12라운드 전체 런
- 영구 성장·재화·BM
- 서버 저장과 계정
- 정식 밸런스 수치

## 현재 더미 데이터

- 라운드 배치: `app.js`의 `ROUND_DATA`
- 능력: `app.js`의 `ABILITIES`
- 색·기호: `app.js`의 `COLOR_META`
- 캐릭터 역할: `app.js`의 `ACTOR_META`

상세 구현 규칙과 변경 내역은 `docs/Project_TTT_저격_포트폴리오_설계안.md`를 기준으로 한다.
