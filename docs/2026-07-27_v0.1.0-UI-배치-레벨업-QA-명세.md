# 룬 트레이스 v0.1.0 UI 배치·레벨업·QA 명세

- 작성일: 2026-07-27
- 상태: UI 방향 확정 및 긴급 버그 수정 요청
- 적용 대상: `rune-trace`
- 범위: UI 배치, 상태 표현, 레벨업 선택창 복구, 기존 디버그 기능 검수
- 제외: 능력·도구 효과와 밸런스 변경

## 1. 확정된 기본 배치

### 왼쪽

- 남은 룬과 보유 능력을 왼쪽에 둔다.
- 룬과 능력은 같은 정보처럼 섞지 말고 별도 구역으로 구분한다.
- 룬은 현재 행동의 주정보, 능력은 보유 상태를 확인하는 보조정보다.
- 능력은 평상시 아이콘만 표시한다.
- 전투 능력은 자동 발동 상태임이 드러나야 하며, 직접 누르는 퍼즐 능력과 버튼 표현을 구분한다.
- 능력 아이콘에는 최소한 현재 단계와 플로어당 사용 가능·사용 완료 상태를 표시한다.

### 중앙

- 7×7 보드를 화면의 가장 중요한 영역으로 유지한다.
- 능력 아이콘을 클릭하면 중앙에 적당한 크기의 상세 설명창을 띄운다.
- PC에서는 호버 설명을 추가할 수 있지만, 호버는 보조 수단이다. 모바일에서도 클릭만으로 같은 정보를 전부 확인할 수 있어야 한다.
- 상세 설명창을 열고 닫는 행위는 턴, 난수, 이동 의도, 능력 사용 상태에 영향을 주지 않는다.

### 하단

- 도구 3종 `탐색 렌즈`, `교차 인장`, `정화 도구`를 보드 하단의 고정 슬롯으로 배치한다.
- 각 슬롯은 아이콘과 우측 하단 보유 수량만 상시 표시한다.
- 보유 수량이 0이면 비활성화하고 선택 글로우를 표시하지 않는다.
- 현재 하단의 `한 수 되돌리기`, `층 초기화`는 일반 플레이 버튼이 아니라 디버그 기능이다. 하단에서 제거하고 QA 패널로 이동한다.

### 오른쪽

- 화면 오른쪽에 `QA 전용` 메뉴 버튼을 추가한다.
- 메뉴 버튼을 누르면 화면 우측에서 디버그 패널이 슬라이드되어 나온다.
- 패널 안에 `한 수 되돌리기`, `층 초기화`와 이후 추가되는 QA 기능을 배치한다.
- 패널 상단에 `QA 전용` 제목과 닫기 버튼을 표시한다.
- 메뉴 버튼 재클릭, 닫기 버튼 또는 Esc로만 닫을 수 있다.
- 패널 바깥과 보드를 클릭해도 패널은 닫히지 않는다.
- 디버그 기능을 실행해도 패널은 자동으로 닫지 않는다. QA가 결과를 연속 확인할 수 있어야 한다.
- 패널은 보드 레이아웃의 폭을 밀어내지 않고 화면 위에 겹쳐서 열린다.
- 보드 상태를 비교하기 쉽도록 강한 딤드는 사용하지 않는다.
- 일반 사용자용 빌드에서는 QA 메뉴와 패널 전체를 숨길 수 있도록 구분한다.

## 2. 도구 상태 표현

### 선택

- 도구를 선택하면 해당 버튼 주변에 글로우 효과를 표시한다.
- 다른 도구를 선택하거나 현재 선택을 취소하면 이전 글로우를 즉시 제거한다.
- 선택만으로 도구를 소비하지 않는다.

### 사용 확정

- 실제 적용이 확정되는 순간 아이콘 우측 하단의 보유 숫자를 1 감소시킨다.
- 수량 변화는 저장 상태와 동시에 반영돼야 하며, 화면만 먼저 줄거나 저장값만 줄어서는 안 된다.

### 소모 피드백

- 수량이 감소하는 순간 버튼을 위아래로 짧게 흔들어 소모를 알린다.
- 흔들림은 한 번만 재생하고 입력을 방해하거나 연속으로 반복하지 않는다.
- 권장 길이는 약 150~220ms다.
- 동작 감소 설정이 켜진 환경에서는 흔들림 대신 짧은 밝기 변화로 대체한다.

## 3. 보드 위 정보 표시 우선순위

한 대상 또는 인접 위치에 여러 예고 정보가 겹치면 아래 순서를 따른다.

1. 처치 예정
2. 이동 화살표
3. 오염 예정

구현 규칙:

- 처치 예정 대상의 알파값 감소와 추후 추가할 처치 아이콘을 가장 강하게 유지한다.
- 이동 화살표는 몬스터 내부가 아니라 현재 칸과 목적지 칸 사이에 표시한다.
- 오염 예정 표시는 가장 낮은 강조도로 표시한다.
- 처치 예정과 겹치는 이동·오염 예고는 완전히 다른 결과처럼 보이지 않도록 약하게 낮춘다.
- 미리보기와 실제 처리 결과는 반드시 일치해야 한다.

## 4. 보스 표시

### 방어막

- 방어막이 1개 이상 남아 있는 보스 몬스터에 굵은 하늘색 외곽선을 표시한다.
- 몬스터 위에 알파값이 낮은 하늘색 패널을 한 겹 씌운다.
- 방어막이 모두 소모되면 외곽선과 패널을 즉시 제거한다.
- 방어막 피격과 코어 처치를 같은 표현으로 처리하지 않는다.

### 변형 효과

- 현재 보스 변형 효과는 화면 상단에 텍스트로 표시한다.
- 최소 표기는 변형 이름과 핵심 효과다.
- 스테이지 진입 안내와 실제 플레이 상단 표기가 서로 달라서는 안 된다.

### 미결 사항

- 외곽선과 패널만으로는 방어막이 2개 이상일 때 정확한 잔여 수량을 구분하기 어렵다.
- 잔여 수량을 상단 텍스트에 함께 적을지, 보스 주변에 `×N`으로 적을지는 추가 확정이 필요하다.

## 5. 능력 상세 설명

- 능력 아이콘을 클릭하면 중앙 상세 설명창을 연다.
- 상세 설명에는 이름, 분류, 현재 단계, 현재 효과, 사용 가능·사용 완료 상태를 표시한다.
- 성장 가능 능력은 현재 단계만 표시하며, 다음 단계 효과는 레벨업 선택창에서 보여준다.
- 설명창 바깥을 누르거나 닫기 버튼을 누르면 닫힌다.
- 설명창이 열려 있을 때 보드 입력이 함께 발생하면 안 된다.
- PC 호버 툴팁은 같은 내용을 축약해 제공할 수 있다.

## 6. 레벨업 선택창 확정 동작

- EXP가 기준치에 도달하면 해당 룬 행동의 결과 처리가 끝난 직후 레벨업 선택 모달을 중앙에 표시한다.
- 능력 선택 전에는 다음 룬 입력, 다음 턴, 되돌리기, 플로어 초기화, 결과 진행을 실행할 수 없다.
- 모달 바깥 딤드 화면을 누르면 선택을 취소하지 않고 모달만 감춘다.
- 감춘 상태에서는 `능력 선택 보기` 버튼 또는 보드 배경 입력으로 같은 모달을 다시 표시한다.
- 감췄다가 다시 열어도 카드 후보를 재추첨하지 않는다.
- 미선택 레벨업은 저장하고 강제 종료 후에도 같은 후보와 순서로 복원한다.
- 한 행동에서 레벨업이 여러 번 발생하면 낮은 레벨부터 하나씩 연속 처리한다.
- 레벨업과 플로어·스테이지 결과가 동시에 발생하면 레벨업 선택을 먼저 처리한 뒤 결과창을 표시한다.
- 단, 챕터 마지막 플로어 종료 시 대기 중인 레벨업을 생략하는 기존 확정 규칙은 유지한다.

## 7. 긴급 버그 수정 요청

### 증상

- 현재 레벨업 선택창이 보이지 않는다.
- 미선택 레벨업 상태가 남아 게임 진행도 되지 않는다.

### 심각도

- 진행 차단 버그로 분류한다.
- UI 개편과 별개로 우선 수정한다.

### 조사 지점

- EXP 획득 후 `pendingLevelUps`가 증가하는지
- 룬 행동 종료 후 대기 모달 처리 함수가 반드시 호출되는지
- 다른 모달 또는 플로어 결과가 레벨업 모달을 덮어쓰는지
- 모달 상태값은 `levelup`인데 딤드와 패널의 표시 클래스가 빠지는지
- 감추기 상태와 실제 닫힘 상태가 혼동되는지
- 저장 복원 후 후보 목록이 비어 모달 생성이 중단되는지
- 디버그 버튼으로 EXP·레벨 상태를 변경했을 때 정상 처리 경로를 우회하는지

원인은 재현 후 확정한다. 위 항목 중 하나를 임의로 원인이라고 가정해 부분 수정하지 않는다.

## 8. QA 전용 패널 및 버튼 검수 요청

현재 보드 하단에 있는 `한 수 되돌리기`, `층 초기화`가 기존 디버그 버튼이다.

1. 두 버튼을 보드 하단에서 제거하고 우측 슬라이드형 `QA 전용` 패널로 이동한다.
2. `한 수 되돌리기`는 직전 룬 행동 이전의 보드·몬스터·오염·EXP·레벨·능력·이동 의도·난수·대기 결과를 같은 상태로 복원해야 한다.
3. `층 초기화`는 현재 플로어 최초 진입 상태를 복원해야 한다.
4. 두 기능이 미선택 레벨업을 임의로 삭제하거나 능력 후보를 재추첨해서는 안 된다.
5. 기능을 실행할 수 없는 상태에서는 버튼을 비활성화하고 이유를 확인할 수 있게 한다.
6. 작동하지 않거나 일부만 복원되는 상태를 숨기지 말고 실패 조건을 기록한 뒤 수정한다.
7. 버튼 실행 뒤 화면 표시, 실제 상태, 저장 상태가 같은지 확인한다.
8. 이후 QA 버튼을 추가하면 같은 패널에 넣되, 명세에 없는 상태 변경 기능을 임의로 만들었으면 `임의 구현·추정`에 기록한다.

검수 결과는 아래 형식으로 개발 업데이트 문서에 남긴다.

| 버튼 | 목적 | 실행 전 조건 | 기대 결과 | 실제 결과 | 판정 |
|---|---|---|---|---|---|
| 한 수 되돌리기 | 직전 룬 행동 이전 상태 복원 | 직전 행동 기록 존재 | 관련 상태와 저장값 전체 복원 | 개발 검수 후 작성 | 통과/실패 |
| 층 초기화 | 현재 플로어 최초 상태 복원 | 플로어 최초 스냅샷 존재 | 최초 배치·상태·난수 복원 | 개발 검수 후 작성 | 통과/실패 |

## 9. 필수 테스트

| 번호 | 상황 | 통과 기준 |
|---|---|---|
| L-01 | 일반 플로어 진행 중 EXP 기준치 도달 | 1초 이내 레벨업 모달 표시, 카드 선택 가능 |
| L-02 | 레벨업과 플로어 클리어 동시 발생 | 레벨업 선택 후 플로어 결과 표시 |
| L-03 | 한 행동에서 복수 레벨업 발생 | 레벨 순서대로 모달 연속 처리 |

| L-05 | `능력 선택 보기` 또는 보드 배경 입력 | 같은 후보의 모달 복귀 |
| L-06 | 모달 감춘 상태에서 룬 입력 | 룬이 그려지지 않고 모달만 다시 표시 |
| L-07 | 미선택 상태에서 새로고침 | 같은 레벨과 같은 후보 복원 |
| L-08 | 최대 단계 능력 포함 상태 | 최대 단계 카드는 후보에서 제외 |
| L-09 | 챕터 마지막 플로어 종료 | 기존 규칙대로 대기 레벨업 생략 후 챕터 종료 |
| T-01 | 도구 선택 | 선택 슬롯에만 글로우 표시, 수량 유지 |
| T-02 | 도구 사용 확정 | 수량 1 감소, 짧은 상하 흔들림 1회 |
| T-03 | 수량 0 도구 | 선택·사용 불가 |
| B-01 | 보스 방어막 보유 | 굵은 하늘색 외곽선과 반투명 패널 표시 |
| B-02 | 마지막 방어막 소모 | 방어막 표현 즉시 제거, 보스 생존 |
| Q-01 | QA 메뉴 열기·닫기 | 우측 패널이 레이아웃을 밀지 않고 열리며 메뉴 재클릭·닫기·Esc로만 닫힘 |
| Q-01-1 | 패널을 연 채 보드 조작 | 보드·패널 바깥을 눌러도 패널이 유지되고 QA를 계속 진행할 수 있음 |
| Q-02 | 한 수 되돌리기 | 직전 행동 이전의 화면·게임·저장 상태가 모두 일치 |
| Q-03 | 층 초기화 | 현재 플로어 최초 진입 시점의 화면·게임·저장 상태가 모두 일치 |
| Q-04 | 미선택 레벨업 중 QA 기능 | 레벨업 후보 삭제·재추첨·진행 우회 없음 |

데스크톱과 모바일 폭에서 각각 확인하고, 콘솔 오류와 입력 중복이 없어야 한다.

## 10. 임의 구현·추정 기록

이 명세에 없는 세부 상태, 수치, 버튼 기능, 반응형 배치를 개발자가 추정해 구현했다면 개발 업데이트 문서의 `임의 구현·추정` 섹션에 아래 내용을 기록한다.

- 구현한 내용
- 그렇게 판단한 이유
- 기획 확인이 필요한 부분
