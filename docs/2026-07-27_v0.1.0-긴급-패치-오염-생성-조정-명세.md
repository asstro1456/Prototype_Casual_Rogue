# 룬 트레이스 `v0.1.0` 긴급 패치 명세 — 오염 생성 조정

## 1. 문서 상태

- 작성일: 2026-07-27
- 적용 목표: `v0.1.0`
- 유형: 긴급 밸런스 패치
- 범위: 일반 몬스터의 오염 생성량과 예고 방식
- 게임 코드와 기존 기획 문서는 이 문서 작성 시점에 수정하지 않았다.
- 이 문서는 오염 생성 규칙에 한해서 기존 `current-game-design.md`와 `2026-07-27_v0.1.0-개발-전달.md`보다 우선한다.
- 이 문서에 적지 않은 이동·전투·능력·보스 규칙은 변경하지 않는다.

## 2. 문제

- 이동 화살표로 몬스터의 다음 위치는 예측할 수 있지만, 생존 몬스터 전체가 오염을 만들면 플레이어의 한 번의 룬 행동으로 대응할 수 있는 범위를 넘는다.
- 예측 가능한 정보가 실제 대응으로 이어지지 않아 전략이 무너지고 통제할 수 없는 손해로 느껴진다.
- 몬스터 수가 많아질수록 판단 난도가 아니라 오염 생성량이 급격히 증가한다.

## 3. 패치 목표

- 한 턴에 발생 가능한 오염을 플레이어가 대응할 수 있는 수준으로 제한한다.
- 오염 발생 주체와 위치를 룬 확정 전에 보여준다.
- 오염 예정 몬스터를 처치하거나 이동을 막는 선택이 실제 오염 방지로 이어지게 한다.
- 보스·증원으로 몬스터 수가 늘어도 오염량이 자동으로 증가하지 않게 한다.

## 4. 초기 테스트값

| 항목 | 값 |
|---|---:|
| 룬 행동당 오염 예정 몬스터 | 최대 2마리 |
| 플로어당 몬스터발 오염 누적 생성 상한 | 6칸 |
| 이동형 보스의 기본 오염 생성 | 없음 |
| 소환 몬스터의 오염 후보 등록 | 소환 다음 턴부터 |

- `6칸`은 현재 보드에 남아 있는 오염 수가 아니라 해당 플로어에서 몬스터가 성공적으로 생성한 누적 횟수다.
- 정화 도구나 다른 효과로 오염을 제거해도 누적 생성 횟수는 감소하지 않는다.
- 플로어 시작 시 배치된 오염이 있다면 몬스터발 누적 생성 횟수에는 포함하지 않는다.

## 5. 턴 시작 처리

1. 기존 규칙으로 일반 몬스터와 보스의 이동 목적지를 먼저 확정한다.
2. 이동 가능한 목적지가 있는 생존 일반 몬스터만 오염 후보가 된다.
3. 보스는 기본 오염 후보에서 제외한다.
4. 해당 턴에 막 소환된 몬스터는 후보에서 제외한다.
5. 남은 플로어 누적 상한 안에서 일반 몬스터를 최대 2마리까지 무작위로 선정한다.
6. 선정 결과와 무작위 상태를 즉시 고정한다.
7. 선정된 몬스터와 오염될 현재 위치 칸을 룬 확정 전에 표시한다.

선정 수:

```text
min(2, 이동 가능한 일반 몬스터 수, 6 - 몬스터발 누적 생성 횟수)
```

## 6. 오염 생성 조건

오염 예정 몬스터가 다음 조건을 모두 만족하면 이동 후 떠난 원래 칸을 오염시킨다.

- 직접 공격·끝점 참격·유혹·도탄으로 제거되지 않았다.
- 미리 정한 목적지로 실제 이동했다.
- 원래 칸이 이번 룬의 새 흔적으로 점유되지 않았다.
- 원래 칸이 이미 오염됐거나 다른 오브젝트로 점유되지 않았다.

성공적으로 오염을 생성했을 때만 플로어의 몬스터발 누적 생성 횟수를 1 증가시킨다.

## 7. 오염이 발생하지 않는 경우

- 오염 예정 몬스터가 이동 전에 처치됨
- 룬에 목적지가 막혀 정지함
- 이동 가능한 목적지가 없어 정지함
- 유혹으로 룬에 충돌해 처치됨
- 떠날 원래 칸에 이번 턴의 새 룬 흔적이 남음
- 플로어의 몬스터발 오염 누적 생성 횟수가 이미 6에 도달함

실패한 오염은 같은 턴에 다른 몬스터에게 재배정하지 않는다.

## 8. 보스와 소환 몬스터

- 이동형 보스는 기본적으로 이동해도 오염을 만들지 않는다.
- 보스가 오염을 만드는 기능은 추후 별도 보스 변형 효과로만 추가한다.
- 증원 소환으로 등장한 몬스터는 소환된 턴에 이동하거나 오염을 만들지 않는다.
- 소환 몬스터는 다음 턴부터 다른 일반 몬스터와 같은 조건으로 오염 후보가 될 수 있다.
- 보스와 소환으로 전체 몬스터 수가 늘어도 턴당 최대 2마리와 플로어당 누적 6칸 상한은 변하지 않는다.

## 9. UI 표시

- 오염 예정 몬스터에 전용 오염 아이콘을 표시한다.
- 몬스터의 현재 위치 칸에는 이동 후 오염될 칸임을 나타내는 반투명 예고를 표시한다.
- 이동 화살표와 오염 예고를 동시에 볼 수 있어야 한다.
- 오염 예정 몬스터가 처치 예정이면 몬스터·화살표·오염 예고의 알파값을 함께 낮춘다.
- 경로를 변경하면 처치 여부와 오염 발생 미리보기를 즉시 갱신한다.
- 실제 결과와 미리보기 결과가 항상 일치해야 한다.

## 10. 처리 순서

1. 이동 목적지와 오염 예정 몬스터 확정
2. 룬 경로 및 능력 결과 미리보기
3. 직접 공격
4. 끝점 참격
5. 유혹
6. 도탄
7. 생존 몬스터 이동
8. 이동에 성공한 오염 예정 몬스터의 원래 칸 오염
9. 보스 증원 소환
10. 클리어·실패 판정과 저장

## 11. 저장·되돌리기

다음 상태를 저장한다.

- 해당 턴의 오염 예정 몬스터 식별자
- 각 몬스터의 이동 목적지
- 오염 후보 선정에 사용한 무작위 상태
- 플로어의 몬스터발 오염 누적 생성 횟수

규칙:

- 경로 취소는 오염 예정 대상을 다시 추첨하지 않는다.
- 한 수 되돌리기는 당시 오염 예정 대상과 누적 횟수를 함께 복원한다.
- 플로어 초기화는 플로어 입장 시점의 무작위 상태를 복원해 같은 행동에는 같은 결과가 나오게 한다.
- 강제 종료와 복귀로 오염 예정 대상을 다시 추첨할 수 없다.

## 12. 수정 제외

- 몬스터 이동 목적지 선정 규칙
- 이동 화살표 위치
- 오염 칸의 기본 배치 제한
- 오염 무시 능력
- 정화 도구
- 유혹 능력
- 보스 증원 소환 위치
- 플로어 구조와 룬 행동 수

## 13. 검증 항목

- 생존 몬스터가 많아도 한 룬 행동에 오염 예정 대상이 2마리를 넘지 않는가.
- 몬스터발 누적 오염이 플로어당 6칸을 넘지 않는가.
- 정화 후에도 누적 생성 횟수가 감소하지 않는가.
- 오염 예정 몬스터를 처치하면 오염이 발생하지 않는가.
- 새 룬으로 목적지를 막아 정지시키면 오염이 발생하지 않는가.
- 실패한 오염이 다른 몬스터에게 재배정되지 않는가.
- 보스가 기본 이동으로 오염을 만들지 않는가.
- 소환 몬스터가 소환 다음 턴부터만 후보가 되는가.
- 미리보기·실제 결과·저장 복귀 결과가 일치하는가.
- 되돌리기·초기화·강제 종료로 대상을 재추첨할 수 없는가.

## 14. 플레이 테스트 조정 기준

- 턴당 2개와 누적 6칸에서도 전략이 자주 무너지면 턴당 상한을 1개로 낮춘다.
- 몬스터 수 증가를 이유로 오염 상한을 자동으로 올리지 않는다.
- 상한 조정은 평균뿐 아니라 오염 때문에 계획한 경로를 포기한 비율과 오염 예정 몬스터를 의도적으로 처치·차단한 비율을 함께 본다.
