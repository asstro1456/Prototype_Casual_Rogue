# 1. 프로젝트 요약

## 기획 질문

캐주얼 퍼즐의 단순한 입력을 유지하면서 한 번의 행동에 여러 판단을 만들 수 있는가.

## 제안한 해법

룬 경로를 직접 그려 몬스터를 처치합니다. 완성한 경로는 흔적으로 남아 다음 룬을 놓을 공간을 줄입니다. 공격이 현재의 이득인 동시에 미래 행동의 비용이 됩니다.

| 항목 | 현재 구조 |
|---|---|
| 보드 | 7×7 |
| 핵심 입력 | 제시된 룬 경로를 보드에 직접 그리기 |
| 플로어 | 룬 최대 4회 |
| 스테이지 | 3개 플로어 |
| 챕터 | 3개 스테이지, 총 9개 플로어 |
| 성장 | 직접 처치 EXP와 챕터 내부 능력 선택 |
| 실패 자원 | 체력 대신 남은 배치 공간 |

# 2. 코어 플레이와 판정

## 행동 흐름

룬 형태와 이동·오염 예정 확인  
↓  
배치 위치와 방향 탐색  
↓  
보드에 룬 직접 입력  
↓  
직접 공격과 능력 효과 처리  
↓  
몬스터 이동과 오염 생성  
↓  
다음 룬을 위한 공간 판단  
↓  
클리어 또는 실패

## 한 번의 행동에서 비교하는 가치

1. 현재 몇 명의 적을 직접 처치할 수 있는가
2. 다음 룬을 놓을 빈 공간이 얼마나 남는가
3. 이동 예정인 적을 능력 효과로 이용할 수 있는가
4. 직접 처치 EXP를 얼마나 확보할 수 있는가
5. 보스의 다음 위치와 변형에 대응할 수 있는가

## 핵심 규칙

> 완성한 룬은 흔적으로 남아 보드 공간을 차지하며, 다음 룬을 놓을 수 없으면 패배한다.

- 각 플로어에는 룬 네 개가 제시됩니다.
- 룬은 직각 회전과 좌우 반전을 허용합니다.
- 경로 위 몬스터를 직접 공격합니다.
- 완성 경로는 흔적으로 남습니다.
- 흔적과 오염 칸에는 기본적으로 새 룬을 놓을 수 없습니다.
- 잘못된 입력은 행동으로 소비하지 않습니다.

## 클리어와 실패

| 구분 | 판정 |
|---|---|
| 일반 플로어 클리어 | 일반 몬스터 전멸 또는 룬 네 개 완성 |
| 보스 플로어 클리어 | 네 번째 룬 행동까지 보스 처치 |
| 공간 부족 실패 | 남은 룬 중 어느 것도 현재 보드에 배치 불가 |
| 보스전 실패 | 네 번째 룬 처리 후 보스 생존 |

# 3. 차별점

## 직접 입력과 즉시 결과

버튼으로 룬을 배치하지 않고 보드에 직접 그립니다. 입력 경로가 공격과 흔적으로 바로 전환되어 조작과 결과를 짧게 설명할 수 있습니다.

## 공격이 곧 공간 소모

많이 처치한다고 항상 좋은 것은 아닙니다. 현재 처치에 유리한 긴 경로가 다음 룬의 배치 공간을 막을 수 있습니다.

## 공개 정보로 판단

몬스터 이동과 오염 예정은 행동 전에 보여줍니다. 무작위는 상황을 만들지만 플레이어가 결정하는 순간의 결과는 고정합니다.

## 장르 결합 기준

| 장르 | 가져온 요소 | 줄인 요소 |
|---|---|---|
| 캐주얼 | 직접 입력, 짧은 플로어, 최소 메뉴 | 대기와 복잡한 관리 |
| 퍼즐 | 공간 관리, 예측, 회전·반전 | 정답 암기 |
| 로그라이크 | 능력 선택, 빌드, 챕터 초기화 | 장시간 런과 과도한 자원 |

# 4. 세션과 성장 구조

## 세션

| 단위 | 구성 | 역할 |
|---|---:|---|
| 플로어 | 룬 최대 4회 | 짧은 문제 상황 |
| 스테이지 | 3개 플로어 | 성장 최소치와 판단 숙련 확인 |
| 챕터 | 3개 스테이지 | 하나의 빌드 완성 |

- 목표 플로어 시간: 1~3분
- 목표 스테이지 시간: 5~10분
- 목표 챕터 시간: 15~30분
- 플로어 클리어마다 저장합니다.
- 레벨·EXP·능력은 챕터 동안 유지하고 챕터 종료 시 초기화합니다.

## 성장

- 일반 몬스터 직접 처치 시 EXP 1을 획득합니다.
- 능력 추가 처치는 EXP를 지급하지 않습니다.
- 레벨업 요구치는 챕터 안에서 증가하지 않습니다.
- 레벨업 시 능력 카드 최대 3장을 제시합니다.
- 최대 단계 능력은 후보에서 제외합니다.

전투 능력은 추가 처치로 공간을 확보하고, 퍼즐 능력은 직접 경로와 EXP 획득을 안정화합니다. 두 계열이 같은 룬 배치 안에서 서로 보완되도록 설계했습니다.

# 5. 능력과 빌드

## 설계 목표

> 능력은 수치 상승에 그치지 않고 경로 선택과 공간 운용 방식을 바꾼다.

| 능력 | 분류 | 단계 | 플레이 변화 |
|---|---|---:|---|
| 유혹 | 전투 | 3 | 새 룬에 이동이 막힌 몬스터를 룬에 충돌시킴 |
| 도탄 | 전투 | 3 | 일반 몬스터 2체 이상 직접 처치 시 가까운 대상 추가 공격 |
| 끝점 참격 | 전투 | 3 | 룬 끝점과 마지막 진행 방향을 추가 공격 범위로 사용 |
| 오염 무시 | 퍼즐 | 1 | 플로어당 한 번 오염 칸 1개 통과 |
| 룬 연결 | 퍼즐 | 1 | 기존 룬 끝점에서 새 룬을 잇고 이전 흔적 제거 |
| 룬 교체 | 퍼즐 | 1 | 플로어당 한 번 남은 룬 하나를 다른 기본 형태로 교체 |

## 빌드 예시

### 공격 확장

도탄과 끝점 참격으로 한 번의 룬에서 처리하는 범위를 늘립니다. 많은 적을 처리해 다음 룬의 공간을 확보합니다.

### 이동 예측·충돌

유혹과 이동 화살표를 이용합니다. 직접 공격하지 못한 몬스터의 예약 이동 칸을 룬으로 막아 추가 처치를 만듭니다.

### 공간·경로 유연성

오염 무시, 룬 연결, 룬 교체로 후반 배치 가능성을 안정화합니다. 직접 처치 경로를 유지해 EXP를 확보합니다.

## 안전장치

- 한 대상은 한 번의 룬 행동에서 최대 1회만 피격됩니다.
- 능력으로 발생한 처치는 다른 능력을 연쇄 발동시키지 않습니다.
- 미리보기와 실제 처리 결과를 일치시킵니다.
- 특정 능력 없이도 보스를 공략할 수 있어야 합니다.

# 6. 보스 시스템

## 역할

보스는 현재 빌드가 필요한 성장 최소치를 채웠는지 확인하는 관문입니다. 스테이지 1·2는 가벼운 확인, 스테이지 3은 완성된 빌드와 공간 판단을 확인합니다.

## 기본 이동형 보스

- 일반 몬스터보다 먼저 이동 칸을 예약합니다.
- 이동 방향은 행동 전에 공개합니다.
- 한 번의 룬 행동에서 최대 1회만 피해를 받습니다.
- 새 룬으로 예약 이동 칸을 막으면 돌진 충돌 피해를 줄 수 있습니다.
- 완전히 갇히면 주변 흔적·오염·일반 몬스터 중 하나를 제거하고 탈출합니다.

## 변형

| 스테이지 | 변형 | 공략 변화 |
|---|---|---|
| 1 | 약점 표식 | 표식을 룬 경로가 직접 통과하면 보스 피격 |
| 2 | 수호 연결 | 연결된 일반 몬스터 처치 시 보스 피격 |
| 3 | 증원 소환 | 보스가 피격 후 생존하면 일반 몬스터 1체 소환 |

방어막, 필요 타격 수, 변형은 스테이지 진입 시 먼저 공개합니다. 특정 능력이나 구매형 도구를 필수로 요구하지 않습니다.

# 7. UX와 정보 설계

## 정보 우선순위

1. 처치 예정
2. 몬스터·보스 이동 화살표
3. 오염 예정

## 표시 규칙

- 처치 예정 대상은 알파값을 낮춥니다.
- 이동 화살표는 몬스터 내부가 아니라 현재 칸과 목적지 사이에 배치합니다.
- 오염 대상과 생성 예정 칸을 행동 전에 표시합니다.
- 능력은 평소 아이콘으로 유지하고 클릭 또는 호버로 상세 설명을 엽니다.
- 레벨업 선택은 화면의 최상위 모달로 표시합니다.
- 모달을 감춘 뒤 화면 어디를 클릭해도 다시 확인할 수 있습니다.
- QA 패널은 게임 보드를 가리지 않는 화면 밖에 둡니다.

## 공정성

- 입력 중 무작위 이동 결과를 바꾸지 않습니다.
- 종료·복귀·초기화로 같은 상태의 결과를 다시 추첨할 수 없게 합니다.
- 실패 원인을 보드와 결과 화면에서 확인할 수 있어야 합니다.
- 중요한 상태는 색상만으로 구분하지 않습니다.

# 8. 문제 발견과 개선

## 프로토타입 변화

| 단계 | 확인한 문제 | 판단 | 반영 |
|---|---|---|---|
| 인접 블록 제거형 | 항상 다수 타격이 유리함 | 현재 이득에 다음 행동 비용 필요 | 흔적 유지와 공간 부족 실패 |
| 실시간 디펜스 | 시간 압박이 경로 판단을 방해 | 생각할 시간 보장 | 턴제 이동과 방향 사전 공개 |
| 초기 룬 트레이스 | 오염이 예측 전략을 무효화 | 공개 정보가 실제 계획으로 이어져야 함 | 오염 예정 공개와 생성 상한 |
| 이동형 보스 | 타격 수단 부족, 갇힘 발생 | 보드 규칙을 이용하되 진행 차단 제거 | 돌진 충돌과 탈출 이동 |

## 사례 1. 오염 과다

### 문제

몬스터 동선은 예측할 수 있었지만 오염이 빠르게 늘어 계획한 경로가 무효화됐습니다.

### 수정

- 행동당 오염 대상 최대 2체
- 플로어당 몬스터 오염 최대 6칸
- 실제 이동한 몬스터만 이전 칸 오염
- 취소된 오염 역할을 같은 턴에 재배정하지 않음
- 보스는 오염 대상에서 제외

## 사례 2. 이동 화살표

몬스터 내부의 화살표가 상태 정보와 겹쳤습니다. 현재 칸과 목적지 칸 사이로 이동해 대상과 방향을 분리했습니다.

## 사례 3. 보스 타격과 갇힘

직접 경로 외 타격 수단이 부족하고 보스가 흔적에 갇혔습니다. 예약 칸 충돌, 약점 표식, 수호 연결, 탈출 이동으로 공략 수단과 예외 처리를 함께 보완했습니다.

# 9. 로그와 초기 플레이테스트

## 로그 범위

- 세션 시작·종료·복귀
- 스테이지·플로어 진입과 종료
- 룬 선택과 경로 결과
- 직접·능력 처치
- 보스 변형과 피격
- 실패·재시도·저장 복원

## 외부 초행 사용자 결과

본인과 QA 반복 기록을 제외한 초행 사용자 3명의 v1.0.0 로그입니다. 초기 사용성 방향만 확인하며 재미와 시장성을 확정하지 않습니다.

| 항목 | 결과 | 해석 |
|---|---:|---|
| 외부 초행 사용자 | 3명 | 소규모 방향 확인 |
| 첫 플로어 클리어 | 3명 · 100% | 초행 사용자의 첫 플로어 진행 가능성 |
| 챕터 완료 | 2명 · 66.7% | 나머지 1명은 스테이지 3 플로어 8 진입 |
| 플로어 종료 판정 | 36회 | v1.0.0 기록 |
| 플로어 클리어 | 35회 · 97.2% | 진행 가능성 확인 |
| 플로어 실패 | 1회 · 2.8% | `success: false` 판정 |
| 재시도 상태 완료 | 4회 | 4회 모두 클리어 |
| 플로어 경과 시간 | 평균 약 37초 · 중앙값 약 31초 | 목표 1~3분보다 짧음 |
| 완주자 챕터 활동 시간 | 약 7.2분 · 14.3분 | 목표 15~30분보다 짧은 사례 |

### 해석

- 현재 난도와 판단 밀도는 목표보다 낮을 가능성이 있습니다.
- 재시도 표식은 실패 수가 아니라 자발적 초기화와 재도전을 포함합니다.
- 플로어 경과 시간은 진행 중 모달·대기를 포함하고 결과 모달을 제외합니다. 현재 구현에서는 탭 비활성 시간도 포함될 수 있습니다.
- 5~10명의 추가 초행 테스트에서 첫 행동, 입력 실패, 스테이지 시간과 재시도를 다시 확인합니다.
