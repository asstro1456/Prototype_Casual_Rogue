# 룬 트레이스 포트폴리오 14페이지 구성 초안

- 기준 버전: `v0.1.0`
- 목적: 회사 제출용 게임 시스템 기획 포트폴리오
- 작성 단계: 페이지 구성 및 핵심 문장 초안
- 제외: BM, 콘텐츠 확장 로드맵
- 표기:
  - **확정:** 현행 기획
  - **초기값:** 프로토타입 조정 가능
  - **검증 예정:** 아직 성과로 주장하지 않음

### 제목

**RUNE TRACE · 룬 트레이스**

### 한 줄 소개

> 예고된 몬스터의 움직임을 읽고 네 개의 룬으로 경로를 설계하는 캐주얼 퍼즐 로그라이트

### 핵심 단어

`7×7 경로 퍼즐` · `5~10분` · `능력 빌드` · `이동형 보스`

### 하단 정보

- 역할: 시스템·콘텐츠·UX·밸런스·지표 설계
- 프로토타입: Web `v0.1.0`
- 기간·기여도: 최종 입력

### 화면

- 대표 보드 1장

## 2페이지. 코어 루프 및 플레이 요약

### 핵심 문장

> 한 번의 룬으로 현재 처치, 다음 이동, 남은 공간, 성장 경험치를 함께 판단한다.

### 행동 루프

```text
이동·오염 예고
→ 룬 경로 탐색
→ 직접 입력
→ 공격·능력 처리
→ 몬스터 이동·오염
→ 다음 룬 또는 클리어
```

### 성장 루프

```text
직접 처치
→ EXP
→ 능력 선택
→ 빌드 형성
→ 보스 관문
```

### 핵심 단어

`공간 관리` · `예측 전투` · `한 수의 다중 가치` · `짧은 런`

### 화면

- 코어 루프 도식
- 룬 입력 전·후 비교

## 3페이지. 장르 분석 — 캐주얼×퍼즐×로그라이크

### 핵심 문장

> 캐주얼이 진입을 만들고, 퍼즐이 한 수의 판단을 만들며, 로그라이크가 다음 판의 이유를 만든다.

| 장르 | 가져온 요소 | 배제·축소한 요소 |
|---|---|---|
| 캐주얼 | 단일 경로 입력, 짧은 스테이지 | 체력 대기, 과도한 메뉴 |
| 퍼즐 | 예측, 공간 관리, 회전·반전 | 정답 암기 중심 구성 |
| 로그라이크 | 능력 선택, 빌드, 챕터 초기화 | 장시간 런, 과도한 자원 |

### 핵심 단어

`즉시 이해` · `반복 선택` · `챕터 초기화` · `낮은 재진입 부담`

### 근거

- 퍼즐 시장 수요는 존재하지만 소재 경쟁은 포화
- 단순 매치보다 실제 플레이에서 바로 보이는 경로 입력 필요

## 4페이지. 서브컬처 캐주얼 분석

### 작성 상태

**사용자 작성 영역**

### 권장 구성

1. 공고에서 말하는 `서브컬처 캐주얼`의 의미
2. 캐주얼 조작과 캐릭터 매력의 역할 분담
3. 주요 사례 2~3개
4. 진입성·잔존·수집 동기의 관계
5. 룬 트레이스에서 적용하거나 제외할 요소

### 작성 키워드

`캐릭터 후킹` · `수집` · `관계·서사` · `가벼운 조작` · `정서적 잔존`

### 주의

- 현재 프로토타입에 없는 캐릭터 시스템을 구현된 것처럼 쓰지 않는다.
- `서브컬처 게임`이라고 단정하기보다 공고 장르를 분석하고 기획 판단으로 연결한다.

## 5페이지. 시장 근거와 타깃층

### 핵심 문장

> 학생은 사용성 검증층이며, 실제 퍼즐 수요는 더 넓은 연령대로 열어둔다.

### 타깃

| 구분 | 가설 |
|---|---|
| 사용성 핵심층 | 16~24세 |
| 상업 가설층 | 20~44세 캐주얼 퍼즐 이용자 |
| 상황 | 쉬는 시간, 통학, 대기 |
| 목표 단위 | 5~10분 스테이지 |

### 조사 숫자

- 한국 모바일 이용자 중 퍼즐·퀴즈 선호 상위 3개 선택: `38%`
- 2024년 한국 퍼즐 다운로드 추정: `약 8,800만 건`
- 글로벌 퍼즐 매출: 전년 대비 `+14%`
- 글로벌 퍼즐 다운로드: 전년 대비 `-3%`

### 해석

`수요 존재` · `성숙 시장` · `차별화 필요` · `실제 잔존 검증 필요`

### 화면

- 숫자 3~4개 인포그래픽
- `시장 사실 → 설계 반영` 연결

## 6페이지. 기획 의도

### 문제

- 캐주얼 퍼즐: 이해하기 쉽지만 성장 이유가 약해질 수 있음
- 로그라이크: 선택은 깊지만 한 판과 정보량이 무거워질 수 있음

### 의도

> 단순한 경로 입력 위에 능력 선택과 보스 관문을 얹어, 짧은 플레이와 빌드 성장을 동시에 제공한다.

### 체력을 제거한 이유

> 피해 숫자보다 오염과 흔적으로 줄어드는 배치 공간이 현재 조작과 더 직접적으로 연결된다.

### 설계 목표

`한 번에 이해` · `다음 수 예측` · `짧은 성장` · `실패 원인 인지`

### 검증 질문

1. 설명 없이 첫 룬을 그릴 수 있는가
2. 예고 정보로 다음 수를 계획할 수 있는가
3. 능력 선택이 다음 라운드 동기가 되는가

## 10페이지. 능력과 성장 구조

### 성장

- 직접 본체 처치: EXP 1
- EXP 7마다 레벨업 — **초기값**
- 후보 최대 3장, 같은 확률
- 최대 단계 카드 제외
- 챕터 목표 선택 약 6회 — **초기 목표**

### 두 계열

| 계열 | 역할 | 보상 방향 |
|---|---|---|
| 전투 | 추가 처치·공간 확보 | 전멸·안정성 |
| 퍼즐 | 경로 규칙 변화 | 직접 EXP·성장 안정 |

### 핵심 문장

> 전투 능력은 공간을 만들고, 퍼즐 능력은 더 좋은 직접 경로를 만든다.

### 레벨업 UX

`턴 종료 후 모달` · `딤드 클릭으로 보드 확인` · `선택 전 진행 차단` · `후보 고정`

| 룬 연결 | 이전 흔적 제거·공간 재구성 | 플로어당 1회 |
| 룬 교체 | 남은 룬 형태 변경 | 플로어당 1회 |

### 처리 순서

`직접 공격 → 끝점 참격 → 유혹 → 도탄`

### 안전장치

`대상당 1회 피격` · `연쇄 발동 없음` · `미리보기 동일`

## 14페이지. 개선 사례·검증 계획·결론

### 문제

> 이동은 보였지만 오염량이 너무 많아 계획 자체가 무너졌다.

### 수정

| 항목 | 변경 |
|---|---|
| 오염 대상 | 행동당 최대 2체 |
| 누적 오염 | 플로어 최대 6칸 |
| 생성 조건 | 표시 대상이 생존·이동했을 때만 |
