# 룬 트레이스 현행 게임 기획

## 문서 상태

- 기준일: 2026-07-27
- 현재 프로토타입: `v0.0.6 · RUNE TRACE`
- 다음 구현 목표: `v0.1.0`
- 목적: 기획 채팅에서 확정된 기준과 다음 프로토타입 구현 규칙을 한곳에 정리한다.
- 상태 표기:
  - **확정**: 다음 구현 기준으로 사용한다.
  - **초기 테스트값**: 프로토타입에 우선 적용하되 플레이 데이터로 조정한다.
  - **검토 중**: 방향만 합의됐거나 추가 결정이 필요하다.
  - **아이디어**: 후보이며 구현 대상으로 확정하지 않았다.

## 1. 게임 목표와 핵심 원칙

### 확정

- 장르는 룬 경로를 직접 그리는 퍼즐 중심 하이브리드 캐주얼 로그라이트다.
- 학생 등 짧은 쉬는 시간과 자투리 시간에 플레이하는 이용자를 주요 대상으로 한다.
- 일반적인 체력은 사용하지 않는다.
- 기존 룬 흔적과 오염 때문에 남은 룬을 하나도 배치할 수 없을 때 실패한다.
- 일반 플로어는 제시된 룬 4개를 모두 사용하거나 모든 적을 먼저 처치하면 클리어한다.
- 적이 남아 있어도 룬 4개를 모두 정상적으로 사용하면 일반 플로어를 클리어할 수 있다.
- 모든 적을 먼저 처치하면 남은 룬을 사용하지 않고 즉시 클리어한다.
- 보스 플로어는 네 번째 룬 처리 전까지 보스를 쓰러뜨려야 하며, 보스가 살아 있으면 실패한다.
- 룬은 회전·좌우 반전된 형태도 인정한다.
- 룬을 별도로 선택하지 않고, 입력한 경로를 남은 룬과 자동 대조한다.
- 완성된 룬 흔적은 해당 플로어가 끝날 때까지 남으며 새 룬의 기본 경로로 다시 사용할 수 없다.
- 생존한 몬스터는 이동하고 빈칸을 오염시켜 남은 배치 공간을 압박한다.

## 2. 챕터·스테이지·플로어 구조

### 확정

- 1챕터는 3스테이지로 구성한다.
- 각 스테이지 마지막 플로어에는 보스를 배치한다.
- 스테이지 1·2의 보스는 현재 성장의 최소치를 확인하는 비교적 가벼운 관문이다.
- 스테이지 3의 보스는 챕터 보스이며, 완성된 빌드와 퍼즐 운용을 확인하는 더 강한 관문이다.
- 스테이지 목표 플레이 시간은 5~10분이다.
- 챕터 목표 플레이 시간은 약 15~30분이다.
- 스테이지 완료 화면은 명확한 종료 지점이며, 플레이어가 그만두거나 다음 스테이지를 이어갈 수 있어야 한다.

### 다음 프로토타입 기준

- 1스테이지는 3플로어로 구성한다.
- 1플로어는 룬 4개로 구성한다.
- 1스테이지는 총 12회의 룬 행동, 1챕터는 총 9플로어와 36회의 룬 행동으로 구성한다.
- 플로어 1은 성장 기반 확보, 플로어 2는 일반 난관, 플로어 3은 보스 역할을 맡는다.
- 목표 활동 시간은 스테이지 P50 5~7분, P90 10분 이내로 검증한다.

### 조정 원칙

- 스테이지가 너무 짧으면 플로어 수를 바로 늘리기보다 보드와 보스의 판단 밀도를 먼저 조정한다.
- 스테이지가 너무 길면 룬 판단, 성장 선택, 전환 연출 중 병목을 먼저 확인한다.

## 3. 챕터 성장과 초기화

### 확정

플로어와 스테이지 사이에 다음 상태를 유지한다.

- 레벨
- 경험치
- 선택한 능력

새 챕터를 시작하거나 현재 챕터를 처음부터 재도전하면 다음 상태를 초기화한다.

- 레벨
- 경험치
- 선택한 능력
- 현재 챕터의 보드·적·오염·룬 구성

다음 상태는 챕터 재도전이나 실패 후에도 유지한다.

- 아웃게임 재화
- 영구 해금 요소
- 기록과 업적
- 사용하지 않은 구매형 도구

### 챕터 재도전

- 플레이어는 현재 빌드로 클리어하기 어렵다고 판단하면 1스테이지 1플로어부터 다시 시작할 수 있다.
- 재도전 시 새로운 배치와 성장 선택지가 나올 수 있도록 해당 챕터의 무작위 구성을 다시 생성한다.
- `한 수 되돌리기`, `플로어 초기화`, `챕터 재도전`은 서로 다른 기능으로 유지한다.

| 기능 | 복귀 지점 | 성장 상태 |
|---|---|---|
| 한 수 되돌리기 | 직전 룬 이전 | 당시 상태로 복원 |
| 플로어 초기화 | 현재 플로어 입장 시점 | 입장 당시 상태로 복원 |
| 챕터 재도전 | 1스테이지 1플로어 | 챕터 성장 전체 초기화 |

## 4. 몬스터 이동

### 현재 `v0.0.6`

- 룬 경로 위 몬스터를 처치한 뒤 생존 몬스터가 이동한다.
- 몬스터는 상하좌우·대각선을 포함한 인접 8칸 중 합법적인 한 칸을 무작위로 선택한다.
- 완성 룬, 오염, 다른 몬스터, 보드 밖으로 이동하지 않는다.
- 이동 가능한 칸이 없으면 정지한다.
- 다음 방향을 미리 보여주지 않기 때문에 룬을 피해 도망가는 것처럼 보이지만 실제로는 거리 계산 없이 무작위로 이동한다.

### 확정된 다음 규칙

1. 플레이어 턴 시작 시 각 몬스터의 다음 이동 목적지를 무작위로 확정한다.
2. 목적지는 상하좌우·대각선 인접 8칸 중 하나다.
3. 다음 칸은 후보에서 제외한다.
   - 보드 밖
   - 기존 룬 흔적
   - 오염 구역
   - 방향 결정 시점에 다른 몬스터가 서 있는 칸
   - 다른 몬스터가 이미 목적지로 예약한 칸
4. 이동 가능한 목적지가 없으면 정지한다.
5. 룬 경로 위 몬스터를 먼저 처치한다.
6. 생존 몬스터는 미리 표시된 목적지로 이동한다.
7. 목적지가 이번 턴에 새로 완성된 룬 흔적으로 막히면 다른 칸을 재탐색하지 않고 현재는 정지한다.
8. 이동과 오염 처리가 끝나면 다음 턴의 목적지를 새로 정한다.

### 룬 충돌 확장 지점

- `장애물 때문에 이동 불가`와 `이번 턴의 새 룬 때문에 이동 불가`를 별도 판정으로 유지한다.
- 기본 결과는 정지다.
- 유혹 능력이 적용되면 새 룬에 막힌 대상이 룬으로 돌진해 피격된다.
- 같은 룬 행동에서 이미 피격된 대상은 유혹으로 다시 피격되지 않는다.

### 이동 단서 UI

- 이동 화살표는 몬스터 몸체 안이 아니라 현재 위치 칸과 이동 예정 칸 사이에 짧게 표시한다.
- 화살촉은 이동 예정 칸을 향하게 한다.
- 목적지까지 이어지는 긴 이동선은 사용하지 않는다.
- 정지 몬스터는 별도의 정지 표시를 사용한다.
- 몬스터를 누르거나 길게 누르면 목적지 칸을 추가로 강조할 수 있다.
- 추후 옵션에서 화살표 표시 켜기·끄기와 크기 조절을 제공한다.
- 되돌리기와 플로어 초기화는 저장된 이동 방향까지 복원하며 방향을 다시 추첨하지 않는다.

### 피격과 방어막

- 모든 몬스터와 보스의 본체는 방어막이 없을 때 1회 피격되면 사망한다.
- 별도의 체력 수치는 사용하지 않는다.
- 피격 시 방어막이 1개 이상이면 방어막 1개를 파괴하고 생존한다.
- 방어막이 0개인 대상이 피격되면 본체가 사망한다.
- 한 대상은 한 번의 룬 행동에서 최대 1회만 피격된다.
- 직접 공격·끝점 참격·유혹·도탄이 같은 대상과 겹치면 처리 순서상 가장 먼저 도달한 효과만 적용한다.
- 직접 공격으로 본체를 처치했을 때만 EXP를 지급한다.
- 직접 공격으로 방어막만 파괴하거나 능력으로 본체를 처치하면 EXP를 지급하지 않는다.
- UI에는 체력 바 대신 남은 방어막 수와 본체 상태를 표시한다.

## 5. 구매형 도구

### 설계 원칙

- 기본 게임에 의도적인 불편을 만든 뒤 해결책을 판매하지 않는다.
- 정상적인 퍼즐은 도구 없이도 해결할 수 있어야 한다.
- 도구는 귀찮음을 줄이거나 단발성 실패를 보완하는 선택적 수단이다.
- 도구는 능력이나 빌드를 대신하지 않는다.
- 구매형 도구는 세 종류만 유지한다.

### 5.1 탐색 렌즈

역할: 현재 턴의 효율적인 룬과 경로 정보를 제공한다.

작동 흐름:

1. 렌즈를 활성화하면 화면을 딤드 처리하고 보드와 후보 룬을 강조한다.
2. 남은 모든 룬, 회전·좌우 반전 형태, 합법적인 경로를 검사한다.
3. 가장 많은 몬스터를 처리할 수 있는 룬을 모두 강조한다.
4. 후보 룬을 클릭하면 해당 룬의 최대 처리 경로를 보드에 표시한다.
5. 가능한 최대 경로가 여러 개면 동시에 보여주되 룬 하나당 최대 3개만 표시한다.
6. 다른 후보 룬을 클릭하면 표시 경로를 해당 룬의 경로로 바꾼다.
7. 플레이어가 표시된 경로 중 하나를 직접 그린다.
8. 정상 완성 시 렌즈를 소비하고 일반 턴을 처리한다.

예외:

- 최대 처치 수가 0이면 합법적으로 그릴 수 있는 경로를 최대 3개 표시한다.
- 렌즈를 활성화한 뒤에는 표시 경로로 룬 하나를 완성하기 전까지 일반 상태로 이탈할 수 없다.
- 잘못 그은 선은 취소하고 다시 시도할 수 있으며 도구와 턴을 소비하지 않는다.
- 후보 룬과 경로는 렌즈 모드 안에서 자유롭게 변경할 수 있다.
- 게임을 종료했다가 돌아와도 렌즈 모드를 복원한다.
- 보스도 유효 목표 계산에 포함한다. 보스 타격·봉인·약점 등 실제 기믹 진행을 유효 목표로 취급한다.

연출:

- 초기 프로토타입은 화면 가장자리 딤드, 후보 룬 발광, 반투명 경로로 검증한다.
- 실제 리소스 단계에서는 돋보기나 망원경을 들여다보는 연출을 고려한다.

### 5.2 교차 인장

- 다음 룬 하나가 기존에 완성된 룬 흔적의 칸 1개를 통과할 수 있다.
- 기존 흔적을 따라 여러 칸 이동할 수 없다.
- 오염, 봉인, 보스 전용 장애물을 통과하지 않는다.
- 실제로 교차한 룬을 정상 완성했을 때 도구를 소비한다.

### 5.3 정화 도구

- 선택한 오염 칸 1개를 즉시 제거한다.
- 적, 보스, 봉인에는 사용할 수 없다.

### 검토 중

- 챕터 반입 수량과 동일 도구 중복 반입 수량
- 도구 가격과 무료 공급량
- 사용한 도구와 플로어 초기화의 세부 환불 규칙

## 6. 보스 구조

### 설계 원칙 — 확정

- 일반 스테이지 보스는 성장 최소치를 확인하는 가벼운 관문으로 사용한다.
- 챕터 보스는 완성된 빌드를 확인하지만 특정 능력이 없으면 해결할 수 없는 조합을 만들지 않는다.
- 장기적으로는 소수의 기본 보스와 변형 효과를 조합해 반복 가능한 콘텐츠를 만든다.
- `v0.1.0`에서는 이동형 보스 1종만 실제 구현하고 다른 기본형은 문서로 제시한다.
- 프로토타입에서는 보스당 변형을 최대 1개만 적용한다.
- 구매형 도구 없이 기본 룬만으로 해결 가능해야 한다.

### 스테이지 진입 정보

- 스테이지 진입 시 해당 스테이지의 보스 유형과 변형 효과를 공개한다.
- 보스 플로어 진입 시 같은 정보를 다시 표시한다.
- 스테이지 안에서는 보스 정보 화면을 다시 열 수 있어야 한다.
- 보스 본체를 쓰러뜨리는 데 필요한 총 피격 횟수, 이동 방식, 변형 조건과 정확한 수치를 표시한다.
- 무효 룬·오염·소환처럼 공략에 영향을 주는 조건을 숨기지 않는다.
- 강제 종료와 복귀로 보스와 변형 효과를 다시 추첨하지 않는다.
- 챕터를 처음부터 재도전할 때만 보스 조합을 다시 생성한다.

### 이동형 보스 — `v0.1.0`

- 스테이지 1·2 보스는 방어막 1개를 보유해 본체 처치까지 총 2회의 피격이 필요하다.
- 스테이지 3 챕터 보스는 방어막 2개를 보유해 총 3회의 피격이 필요하다.
- 스테이지 1·2 보스 플로어에는 일반 몬스터 3마리를 임시 배치한다.
- 스테이지 3 보스 플로어에는 일반 몬스터 5마리를 임시 배치한다.
- 일반 몬스터 수는 플레이 테스트로 조정하는 초기 테스트값이다.
- 직접 공격·끝점 참격·유혹은 보스를 피격시킬 수 있다.
- 도탄은 보스를 대상으로 선택하지 않는다.
- 보스를 쓰러뜨리면 일반 몬스터가 남아 있어도 즉시 보스 플로어를 클리어한다.
- 일반 몬스터가 남아 있으면 플로어 전멸 보상은 지급하지 않는다.
- 네 번째 룬 처리 후 보스가 살아 있으면 보스전 실패로 판정한다.

이동 규칙:

1. 턴 시작 시 보스가 일반 몬스터보다 먼저 인접 8칸 중 목적지를 예약한다.
2. 보드 밖·기존 흔적·오염·현재 다른 몬스터가 있는 칸은 후보에서 제외한다.
3. 일반 몬스터는 보스의 현재 칸과 예약 목적지를 선택할 수 없다.
4. 목적지가 없으면 보스는 정지한다.
5. 보스의 현재 칸과 목적지 칸 사이에 일반 몬스터보다 구분되는 이동 화살표를 표시한다.
6. 룬 처리가 끝난 뒤 살아 있는 보스는 피격 여부와 관계없이 미리 표시한 목적지로 이동한다.
7. 목적지가 이번 턴의 새 룬에 막히면 유혹이 없을 때는 현재 위치에 정지한다.
8. 유혹이 적용되면 룬으로 충돌해 피격되지만, 같은 룬 행동에서 이미 피격됐다면 방어막을 추가로 잃지 않는다.
9. 직접 공격을 받고 살아남아 새 흔적 위에 서게 된 보스는 다음 턴에 그 흔적 밖으로 이동할 수 있다.
10. 보스 목적지와 첫 위치는 남은 룬 중 최소 하나로 유효 피격을 만들 수 있는 상태만 허용한다.

### 변형 효과 1: 증폭 방어막

- 스테이지 진입 시 기본 방어막에 방어막 1개를 추가한다.
- 최종 방어막 수와 본체 처치까지 필요한 총 피격 횟수를 공개한다.
- `v0.1.0`에서는 스테이지 1·2 보스에만 허용한다.
- 스테이지 3 보스에 적용하면 네 번의 룬을 모두 명중해야 하므로 초기에는 금지한다.

### 변형 효과 2: 증원 소환

- 보스가 피격 후 생존하면 일반 몬스터 1마리 소환을 예약한다.
- 보스 본체가 사망한 피격에서는 소환하지 않는다.
- 한 번의 룬 행동에서 최대 1마리만 소환한다.
- 모든 기존 몬스터와 보스의 이동이 끝난 뒤, 이동을 마친 보스의 인접 8칸 중 합법적인 한 칸에 소환한다.
- 보드 밖·룬 흔적·오염·다른 몬스터가 있는 칸은 후보에서 제외한다.
- 후보가 여러 개면 무작위로 하나를 선택하고, 후보가 없으면 소환하지 않는다.
- 소환될 칸은 룬 확정 전에 유령 몬스터 형태로 미리 표시한다.
- 같은 턴 상태에서는 무작위 결과를 고정해 경로 변경·되돌리기·강제 종료로 재추첨할 수 없게 한다.
- 새로 소환된 몬스터는 해당 턴에 이동하거나 오염을 만들지 않으며 방어막은 없다.

### 문서 전용 확장안

- 도약형 보스
- 약점 순환형 보스
- 특정 룬 무효
- 오염 강화
- 변형 효과 5~6종으로의 확장
- 조합표 `허용 / 조건부 허용 / 금지`

### 생성 안전장치

- 현재 룬과 빌드로 해결 가능해야 한다.
- 특정 능력이나 구매형 도구를 필수로 요구하지 않는다.
- 특정 룬 무효가 있더라도 보스의 필수 피격 횟수만큼 유효한 공격 기회를 보장한다.
- 보스 기본형, 변형, 시드, 룬 풀, 이동 및 소환 무작위 상태를 저장해 불공정 조합을 재현할 수 있게 한다.

## 7. 능력과 성장

### 확정된 기본 방향

능력은 두 갈래로 구성한다.

1. **전투 능력**: 핵앤슬래시처럼 한 번의 룬으로 많은 몬스터를 처리하는 재미
2. **퍼즐 능력**: 룬 배치 규칙과 공간 판단을 변화시켜 퍼즐의 재미를 늘리는 능력

두 계열은 같은 룬 배치 안에서 서로 보완해야 한다.

- 전투 능력은 추가 처치와 플로어 전멸을 통해 아웃게임 재화 수급 편의성을 높인다.
- 퍼즐 능력은 더 좋은 직접 경로를 만들고 직접 처치 EXP와 챕터 내 성장을 안정화한다.
- 전투 능력도 적과 오염 압박을 줄여 챕터 생존에 기여한다.
- 퍼즐 능력도 효율적인 직접 경로를 만들어 플로어 전멸에 기여한다.
- 순수 전투, 순수 퍼즐, 혼합 빌드가 모두 챕터를 끝낼 수 있어야 한다.
- 범용 인게임 특수 자원은 도입하지 않는다. 필요하다면 능력별 횟수 제한만 개별적으로 사용한다.

### 전투 능력 공통 규칙

- 전투 능력은 같은 능력을 다시 선택하면 1단계씩 강화하며 최대 3단계다.
- 직접 처치는 새로 완성한 룬 경로가 통과한 몬스터만 뜻한다.
- 전투 능력으로 피격되거나 처치된 몬스터는 EXP를 주지 않지만 플로어 전멸 판정에는 포함한다.
- 능력으로 발생한 피격과 처치는 다른 능력의 발동 조건이 되지 않으며 연쇄 발동하지 않는다.
- 같은 대상은 한 번의 룬 행동에서 최대 1회만 피격된다.
- 룬을 확정하기 전에 직접 처치와 능력 피격·처치 결과를 미리 보여준다.
- 처치 예정 몬스터는 우선 알파값을 낮춰 표시하고, 실제 리소스 단계에서 처치 예정 아이콘을 추가한다.

### 전투 처리 순서

1. 룬 경로의 직접 피격·처치
2. 끝점 참격
3. 유혹 대상의 룬 충돌
4. 도탄
5. 생존 몬스터와 보스 이동 및 오염 처리
6. 증원 소환
7. 전멸·보스 처치·플로어 클리어 판정

- 앞 단계에서 이미 피격된 대상은 뒤 단계의 대상으로 다시 선택하지 않는다.
- 도탄은 앞선 공간 기반 효과가 처리된 뒤 남은 일반 몬스터를 정리한다.
- 미리보기 계산과 실제 처리에 같은 순서를 사용한다.
- 초기 플레이 테스트에서 과도하게 강하면 처리 순서를 바꾸지 않고 능력 수치나 발동 조건을 조정한다.

### 7.1 유혹

역할: 몬스터의 이동 예고를 이용해 새 룬으로 충돌시키는 전략형 능력.

- 직접 공격과 끝점 참격에서 살아남았고 아직 피격되지 않았으며, 이동 예정 칸이 이번 턴의 새 룬에 막힌 대상을 유혹 대상으로 판정한다.
- 기본 규칙에서는 해당 대상이 정지하지만, 유혹 대상이면 새 룬으로 돌진해 1회 피격된다.
- 1단계는 우선순위가 가장 높은 대상 1마리, 2단계는 2마리, 3단계는 모든 유효 대상을 피격시킨다.
- 이동형 보스도 유혹 대상에 포함한다.
- 우선순위는 룬의 시작점에서 끝점 방향으로 새 흔적을 따라가며, 이동 예정 칸이 먼저 막히는 몬스터부터 판정한다.
- 같은 순번의 후보는 화면 기준 왼쪽을 우선한다.
- 좌우 위치까지 같으면 룬 진행 방향 쪽을 우선하며, 완전히 수평인 진행에서는 위쪽을 우선한다.
- 룬을 확정하기 전에 선택될 몬스터를 미리 표시한다.

### 7.2 도탄

역할: 한 플로어에서 한 번, 다수 직접 처치에 대량 처치로 보상하는 폭발형 능력.

- 한 번의 룬으로 일반 몬스터를 2마리 이상 직접 처치하면 발동한다.
- 한 플로어에서 최초 조건 충족 시 1회만 자동 발동한다.
- 1단계는 일반 몬스터 1마리, 2단계는 2마리, 3단계는 3마리를 추가 피격시킨다.
- 플로어가 바뀌면 발동 가능 상태를 회복한다.
- 도탄은 보스에게 적용하지 않는다.
- 룬 끝점에서 가까운 일반 몬스터부터 단계 수만큼 선택한다.
- 거리는 칸 중심 사이의 직선거리로 비교한다.
- 거리가 같으면 화면 위쪽을 먼저, 세로 위치도 같으면 왼쪽을 먼저 선택한다.
- 남은 대상이 단계 수보다 적으면 남은 대상을 모두 한 번씩 피격시킨다.
- 방어막이 없는 일반 몬스터가 모두 처치되면 즉시 일반 플로어 클리어 상태로 전환한다.
- 룬을 확정하기 전에 이번 발동 여부와 추가 처치 예정 대상을 미리 표시한다.

### 7.3 끝점 참격

역할: 룬의 마지막 진행 방향과 끝점을 이용하는 지속 범위형 능력.

- 공격의 중심은 완성될 룬의 끝점이다.
- 추가 공격은 룬 흔적을 남기지 않는다.
- 1단계는 끝점의 진행 방향 앞쪽 1칸을 추가 공격한다.
- 2단계는 진행 방향 앞쪽의 3칸 폭을 추가 공격한다.
- 3단계는 끝점을 중심으로 한 3×3 범위에서 끝점과 직전 룬 칸을 제외한 7칸을 추가 공격한다.
- 직교 방향 2단계는 전방 중앙과 그 좌우 한 칸을 공격한다.
- 대각선 방향 2단계는 전방 대각선 칸과 그 대각선을 이루는 직교 방향 두 칸을 공격한다.
- 예를 들어 마지막 진행이 우상향이면 2단계 범위는 위·우상단·오른쪽의 3칸이다.
- 3단계는 직교·대각선 모두 끝점 주변 8칸 중 직전 룬 칸 하나를 제외한 7칸이다.
- 보드 밖으로 나간 공격 칸은 보정하지 않고 소멸한다.
- 여러 공격 칸이 같은 보스와 겹쳐도 보스에는 최대 1회의 유효 타격만 적용한다.
- 유효한 끝점이 정해진 순간부터 룬을 확정할 때까지 현재 단계의 공격 범위를 테두리로 미리 표시한다.
- 경로가 변경되거나 취소되면 공격 범위와 처치 예정 표시도 즉시 갱신하거나 복원한다.

### 퍼즐 능력 — `v0.1.0` 임시 확정

퍼즐 능력은 모두 능력별로 플로어당 1회 사용한다. 실제 효과가 발생한 룬을 정상 완성하거나 교체를 확정했을 때만 사용 처리한다.

#### 오염 무시

- 한 번의 룬에서 오염 칸 1개를 통과할 수 있다.
- 통과한 오염은 제거되지 않는다.
- 해당 칸은 룬 형태 판정에는 포함하지만 새 룬 흔적을 남기지 않는다.
- 오염을 실제로 통과한 룬을 정상 완성했을 때 사용 처리한다.
- 다른 오염, 기존 룬 흔적, 보스 장애물은 무시하지 않는다.

#### 룬 연결

- 사용 가능할 때 기존 룬 흔적의 양 끝점을 발광시킨다.
- 발광하는 끝점에서 새 룬을 시작할 수 있다.
- 공유한 끝점은 새 룬 형태의 첫 칸으로 인정한다.
- 새 룬을 정상 완성하면 연결된 이전 룬 흔적 전체를 제거하고 공유 끝점을 새 룬 흔적으로 유지한다.
- 완성 전에 사라질 이전 흔적을 낮은 알파값으로 미리 표시한다.
- `v0.1.0`에서는 성장 단계 없이 단일 효과로 테스트하며 최종 성장 구조는 추후 결정한다.

#### 룬 교체

- 남아 있는 룬 하나를 선택해 다른 룬으로 무작위 교체한다.
- 선택한 룬과 같은 기본 형태는 후보에서 제외한다.
- 회전·반전만 다른 형태는 같은 기본 룬으로 취급한다.
- 현재 보드에서 합법적으로 배치 가능한 룬을 보장하지 않는 순수 무작위로 우선 테스트한다.
- 교체를 확정했을 때 사용 처리한다.
- 되돌리기·플로어 초기화·강제 종료 복귀로 교체 결과를 다시 추첨하지 않는다.
- `v0.1.0`의 성장 단계는 아직 두지 않는다.

### 성장 횟수와 경험치

- 한 챕터에서 몬스터를 약 절반 처치하면 능력을 약 6회 선택하는 것을 목표로 한다.
- 레벨업 요구치는 챕터 안에서 증가시키지 않는 방향이다.
- 적 1체의 직접 처치는 EXP 1을 준다.
- 룬 경로가 직접 통과한 몬스터만 EXP를 주는 방향을 우선한다.
- 전투 능력으로 제거된 몬스터는 공간 확보와 플로어 전멸에는 기여하지만 EXP를 주지 않는다.
- 직접 공격으로 방어막만 파괴한 경우에는 EXP를 주지 않는다.

### 초기 테스트값

- EXP 7마다 레벨업
- 초과 EXP는 다음 레벨로 이월
- 챕터 평균 약 42체 직접 처치 시 성장 선택 6회

적 수와 실제 직접 처치율이 확정되지 않았으므로 `EXP 7`은 테스트 후 조정한다.

### 레벨업 선택

- 레벨업하면 턴 결과 처리가 끝난 직후 능력을 선택한다.
- 처리 순서는 `룬 완성 → 직접 공격 → 끝점 참격 → 유혹 → 도탄 → 이동·오염 → 증원 소환 → 클리어 판정 → 저장 → 능력 선택 → 다음 턴`이다.
- 능력 선택 전까지 게임 진행을 멈춘다.
- 새 능력은 이미 끝난 턴에 소급 적용하지 않고 다음 턴부터 적용한다.
- 챕터 보스를 쓰러뜨려 챕터 종료가 확정되면 미처리 레벨업 선택을 표시하지 않는다.

## 8. 저장과 중단·복귀

### 확정된 원칙

- 플로어 클리어마다 안정적인 체크포인트를 남긴다.

- 되돌리기와 플로어 초기화는 게임 안의 정식 기능으로만 실행한다.

### 권장 구현안

- 로컬 현재 상태는 룬 정상 완성, 능력 선택, 도구 사용 등 되돌릴 수 없는 행동마다 같은 슬롯에 덮어쓴다.
- 플로어 클리어 시 복구용 체크포인트와 클라우드 동기화 지점을 남긴다.
- 룬을 그리는 도중 종료하면 룬을 긋기 전 상태로 돌아간다.
- 룬이 정상 인식된 뒤에는 처치·이동·오염까지 확정된 상태로 복귀한다.
- 탐색 렌즈 사용 중 종료하면 렌즈 모드로 복귀한다.
- 턴 결과는 플레이어에게 보여주기 전에 저장한다.

이 안은 플로어 단위 저장만 사용할 때 생기는 강제 종료 롤백을 막으면서, 저장 기록을 누적하지 않고 최신 상태만 유지한다.
