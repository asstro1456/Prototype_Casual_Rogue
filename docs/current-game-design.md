# 룬 트레이스 현행 게임 기획

## 문서 상태

- 기준일: 2026-07-27
- 현재 프로토타입: `v0.0.6 · RUNE TRACE`
- 목적: 기획 채팅에서 확정된 기준과 다음 프로토타입 구현 규칙을 한곳에 정리한다.
- 상태 표기:
  - **확정**: 다음 구현 기준으로 사용한다.
  - **초기 테스트값**: 프로토타입에 우선 적용하되 플레이 데이터로 조정한다.
  - **검토 중**: 방향만 합의됐거나 추가 결정이 필요하다.
  - **아이디어**: 후보이며 구현 대상으로 확정하지 않았다.

## 1. 게임 목표와 핵심 원칙

### 확정

- 장르는 룬 경로를 직접 그리는 퍼즐 중심 하이브리드 캐주얼 로그라이트다.
- 학생 등 짧은 쉬는 시간과 자투리 시간에 플레이하는 이용자를 주요 대상으로 한다.
- 일반적인 체력은 사용하지 않는다.
- 기존 룬 흔적과 오염 때문에 남은 룬을 하나도 배치할 수 없을 때 실패한다.
- 플레이어는 한 플로어에 제시된 룬 4개를 모두 그리면 플로어를 클리어한다.
- 적을 전부 처치하지 않아도 플로어를 클리어할 수 있다.
- 룬은 회전·좌우 반전된 형태도 인정한다.
- 룬을 별도로 선택하지 않고, 입력한 경로를 남은 룬과 자동 대조한다.
- 완성된 룬 흔적은 해당 플로어가 끝날 때까지 남으며 새 룬의 기본 경로로 다시 사용할 수 없다.
- 생존한 몬스터는 이동하고 빈칸을 오염시켜 남은 배치 공간을 압박한다.

## 2. 챕터·스테이지·플로어 구조

### 확정

- 1챕터는 3스테이지로 구성한다.
- 각 스테이지 마지막 플로어에는 보스를 배치한다.
- 스테이지 1·2의 보스는 현재 성장의 최소치를 확인하는 비교적 가벼운 관문이다.
- 스테이지 3의 보스는 챕터 보스이며, 완성된 빌드와 자원 운용을 확인하는 더 강한 관문이다.
- 스테이지 목표 플레이 시간은 5~10분이다.
- 챕터 목표 플레이 시간은 약 15~30분이다.
- 스테이지 완료 화면은 명확한 종료 지점이며, 플레이어가 그만두거나 다음 스테이지를 이어갈 수 있어야 한다.

### 다음 프로토타입 기준

- 1스테이지는 3플로어로 구성한다.
- 1플로어는 룬 4개로 구성한다.
- 1스테이지는 총 12회의 룬 행동, 1챕터는 총 9플로어와 36회의 룬 행동으로 구성한다.
- 플로어 1은 성장·자원 확보, 플로어 2는 일반 난관, 플로어 3은 보스 역할을 맡는다.
- 목표 활동 시간은 스테이지 P50 5~7분, P90 10분 이내로 검증한다.

### 조정 원칙

- 스테이지가 너무 짧으면 플로어 수를 바로 늘리기보다 보드와 보스의 판단 밀도를 먼저 조정한다.
- 스테이지가 너무 길면 룬 판단, 성장 선택, 전환 연출 중 병목을 먼저 확인한다.

## 3. 챕터 성장과 초기화

### 확정

플로어와 스테이지 사이에 다음 상태를 유지한다.

- 레벨
- 경험치
- 선택한 능력
- 인게임 특수 자원

새 챕터를 시작하거나 현재 챕터를 처음부터 재도전하면 다음 상태를 초기화한다.

- 레벨
- 경험치
- 선택한 능력
- 인게임 특수 자원
- 현재 챕터의 보드·적·오염·룬 구성

다음 상태는 챕터 재도전이나 실패 후에도 유지한다.

- 아웃게임 재화
- 영구 해금 요소
- 기록과 업적
- 사용하지 않은 구매형 도구

### 챕터 재도전

- 플레이어는 현재 빌드로 클리어하기 어렵다고 판단하면 1스테이지 1플로어부터 다시 시작할 수 있다.
- 재도전 시 새로운 배치와 성장 선택지가 나올 수 있도록 해당 챕터의 무작위 구성을 다시 생성한다.
- `한 수 되돌리기`, `플로어 초기화`, `챕터 재도전`은 서로 다른 기능으로 유지한다.

| 기능 | 복귀 지점 | 성장 상태 |
|---|---|---|
| 한 수 되돌리기 | 직전 룬 이전 | 당시 상태로 복원 |
| 플로어 초기화 | 현재 플로어 입장 시점 | 입장 당시 상태로 복원 |
| 챕터 재도전 | 1스테이지 1플로어 | 챕터 성장 전체 초기화 |

## 4. 몬스터 이동

### 현재 `v0.0.6`

- 룬 경로 위 몬스터를 처치한 뒤 생존 몬스터가 이동한다.
- 몬스터는 상하좌우·대각선을 포함한 인접 8칸 중 합법적인 한 칸을 무작위로 선택한다.
- 완성 룬, 오염, 다른 몬스터, 보드 밖으로 이동하지 않는다.
- 이동 가능한 칸이 없으면 정지한다.
- 다음 방향을 미리 보여주지 않기 때문에 룬을 피해 도망가는 것처럼 보이지만 실제로는 거리 계산 없이 무작위로 이동한다.

### 확정된 다음 규칙

1. 플레이어 턴 시작 시 각 몬스터의 다음 이동 목적지를 무작위로 확정한다.
2. 목적지는 상하좌우·대각선 인접 8칸 중 하나다.
3. 다음 칸은 후보에서 제외한다.
   - 보드 밖
   - 기존 룬 흔적
   - 오염 구역
   - 방향 결정 시점에 다른 몬스터가 서 있는 칸
   - 다른 몬스터가 이미 목적지로 예약한 칸
4. 이동 가능한 목적지가 없으면 정지한다.
5. 룬 경로 위 몬스터를 먼저 처치한다.
6. 생존 몬스터는 미리 표시된 목적지로 이동한다.
7. 목적지가 이번 턴에 새로 완성된 룬 흔적으로 막히면 다른 칸을 재탐색하지 않고 현재는 정지한다.
8. 이동과 오염 처리가 끝나면 다음 턴의 목적지를 새로 정한다.

### 룬 충돌 확장 지점

- `장애물 때문에 이동 불가`와 `이번 턴의 새 룬 때문에 이동 불가`를 별도 판정으로 유지한다.
- 기본 결과는 정지다.
- 추후 유혹 계열 능력이 있으면 새 룬에 막힌 몬스터가 룬으로 돌진하도록 결과를 변경할 수 있다.
- 돌진 시 처치·기절·보상 여부는 능력 설계에서 결정한다.

### 이동 단서 UI

- 몬스터 몸체 또는 테두리 안에 짧은 방향 화살표를 표시한다.
- 목적지까지 이어지는 긴 이동선은 사용하지 않는다.
- 정지 몬스터는 별도의 정지 표시를 사용한다.
- 몬스터를 누르거나 길게 누르면 목적지 칸을 추가로 강조할 수 있다.
- 추후 옵션에서 화살표 표시 켜기·끄기와 크기 조절을 제공한다.
- 되돌리기와 플로어 초기화는 저장된 이동 방향까지 복원하며 방향을 다시 추첨하지 않는다.

## 5. 구매형 도구

### 설계 원칙

- 기본 게임에 의도적인 불편을 만든 뒤 해결책을 판매하지 않는다.
- 정상적인 퍼즐은 도구 없이도 해결할 수 있어야 한다.
- 도구는 귀찮음을 줄이거나 단발성 실패를 보완하는 선택적 수단이다.
- 도구는 능력이나 빌드를 대신하지 않는다.
- 구매형 도구는 세 종류만 유지한다.

### 5.1 탐색 렌즈

역할: 현재 턴의 효율적인 룬과 경로 정보를 제공한다.

작동 흐름:

1. 렌즈를 활성화하면 화면을 딤드 처리하고 보드와 후보 룬을 강조한다.
2. 남은 모든 룬, 회전·좌우 반전 형태, 합법적인 경로를 검사한다.
3. 가장 많은 몬스터를 처리할 수 있는 룬을 모두 강조한다.
4. 후보 룬을 클릭하면 해당 룬의 최대 처리 경로를 보드에 표시한다.
5. 가능한 최대 경로가 여러 개면 동시에 보여주되 룬 하나당 최대 3개만 표시한다.
6. 다른 후보 룬을 클릭하면 표시 경로를 해당 룬의 경로로 바꾼다.
7. 플레이어가 표시된 경로 중 하나를 직접 그린다.
8. 정상 완성 시 렌즈를 소비하고 일반 턴을 처리한다.

예외:

- 최대 처치 수가 0이면 합법적으로 그릴 수 있는 경로를 최대 3개 표시한다.
- 몬스터가 모두 제거된 뒤 남은 룬을 편하게 소진하는 용도로 사용할 수 있다.
- 렌즈를 활성화한 뒤에는 표시 경로로 룬 하나를 완성하기 전까지 일반 상태로 이탈할 수 없다.
- 잘못 그은 선은 취소하고 다시 시도할 수 있으며 도구와 턴을 소비하지 않는다.
- 후보 룬과 경로는 렌즈 모드 안에서 자유롭게 변경할 수 있다.
- 게임을 종료했다가 돌아와도 렌즈 모드를 복원한다.
- 보스도 유효 목표 계산에 포함한다. 보스 타격·봉인·약점 등 실제 기믹 진행을 유효 목표로 취급한다.

연출:

- 초기 프로토타입은 화면 가장자리 딤드, 후보 룬 발광, 반투명 경로로 검증한다.
- 실제 리소스 단계에서는 돋보기나 망원경을 들여다보는 연출을 고려한다.

### 5.2 교차 인장

- 다음 룬 하나가 기존에 완성된 룬 흔적의 칸 1개를 통과할 수 있다.
- 기존 흔적을 따라 여러 칸 이동할 수 없다.
- 오염, 봉인, 보스 전용 장애물을 통과하지 않는다.
- 실제로 교차한 룬을 정상 완성했을 때 도구를 소비한다.

### 5.3 정화 도구

- 선택한 오염 칸 1개를 즉시 제거한다.
- 적, 보스, 봉인에는 사용할 수 없다.

### 검토 중

- 챕터 반입 수량과 동일 도구 중복 반입 수량
- 도구 가격과 무료 공급량
- 사용한 도구와 플로어 초기화의 세부 환불 규칙

## 6. 보스 구조

### 확정

- 수제 보스를 무한히 추가하지 않는다.
- 소수의 기본 보스 유형과 추가 효과를 조합해 반복 가능한 콘텐츠를 만든다.
- 추가 효과 후보에는 타수 기믹, 특정 룬 무효, 오염 강화 등이 있다.
- 일반 스테이지 보스는 성장 최소치를 확인하되 까다로운 수제 퍼즐처럼 만들지 않는다.
- 챕터 보스는 일반 보스보다 강하지만 현재 빌드로 해결 불가능한 조합을 만들지 않는다.
- 보스와 변형 효과를 플로어 진입 전에 명확하게 공개한다.

### 초기 실험 규모

- 기본 보스 3종
- 변형 효과 5~6종
- 초기에는 보스당 변형 1개
- 단일 변형 데이터가 충분히 쌓인 뒤 복수 변형을 검토한다.

이 수는 업계 표준이 아니라 검증 가능한 초기 실험 규모다.

### 생성 안전장치

- 조합표를 `허용 / 조건부 허용 / 금지`로 관리한다.
- 현재 룬과 빌드로 해결 가능해야 한다.
- 구매형 도구 없이 해결 가능해야 한다.
- 최소 2개 이상의 유효 전략을 보장하는 것을 목표로 한다.
- 동일 변형의 연속 등장 횟수에 상한을 둔다.
- 보스 기본형, 변형, 시드, 룬 풀을 기록해 불공정 조합을 재현할 수 있게 한다.

## 7. 능력과 성장

### 확정된 기본 방향

능력은 두 갈래로 구성한다.

1. **토벌 계열**: 핵앤슬래시처럼 한 번의 룬으로 많은 몬스터를 처리하는 재미
2. **퍼즐 계열**: 룬 배치 규칙과 공간 판단을 변화시켜 퍼즐의 재미를 늘리는 능력

두 계열은 완전히 분리하지 않고 같은 룬 배치 안에서 서로 보완해야 한다.

- 토벌 능력은 추가 처치와 완전 토벌을 통해 아웃게임 재화 수급 편의성을 높인다.
- 퍼즐 능력은 더 좋은 직접 경로를 만들고 직접 처치 EXP와 챕터 내 성장을 안정화한다.
- 토벌 능력도 적과 오염 압박을 줄여 챕터 생존에 기여한다.
- 퍼즐 능력도 효율적인 직접 경로를 만들어 완전 토벌에 기여한다.
- 순수 토벌, 순수 퍼즐, 혼합 빌드가 모두 챕터를 끝낼 수 있어야 한다.

### 세부 분류 후보

| 계열 | 세부 역할 |
|---|---|
| 토벌 | 범위, 연쇄, 유인 |
| 퍼즐 | 룬 변형, 공간 관리, 배치 보상 |

현재 가장 가능성이 높은 구체 능력 후보는 `유혹`이다.

- 몬스터가 이동하려던 목적지를 새 룬이 막았을 때 기본 정지 대신 룬으로 돌진하게 한다.
- 정확한 처치·기절·보상 규칙은 아직 확정하지 않았다.

### 성장 횟수와 경험치

- 한 챕터에서 몬스터를 약 절반 처치하면 능력을 약 6회 선택하는 것을 목표로 한다.
- 레벨업 요구치는 챕터 안에서 증가시키지 않는 방향이다.
- 적 1체의 직접 처치는 EXP 1을 준다.
- 룬 경로가 직접 통과한 몬스터만 EXP를 주는 방향을 우선한다.
