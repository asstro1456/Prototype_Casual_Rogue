# Project TTT 저격 포트폴리오 설계안

## 1. 지원 포지션 해석

이 포지션은 레벨·콘텐츠 한 분야의 전문 기획자보다 다음에 가깝다.

> 소규모 신규 개발팀에서 시스템·콘텐츠·밸런스를 연결하고, Unity와 데이터 시트로 실제 제작까지 밀어붙이는 서브컬처 캐주얼 로그라이크 제너럴리스트 기획자

평가의 중심은 아이디어의 크기보다 다음 네 가지다.

1. 여러 기획 영역을 하나의 플레이 경험으로 연결하는가
2. 아이디어를 데이터와 제작 단위로 구체화할 수 있는가
3. 테스트 결과를 근거로 수정할 수 있는가
4. 서브컬처·로그라이크·모바일 시장을 실제 플레이 경험으로 이해하는가

## 3. 포트폴리오 전체 전략

### 프로젝트 A — 기존 프로젝트 묶음

증명할 것:

- 로그라이트: 시스템·콘텐츠·방 진행 규칙
- 냥냥스타: 콘텐츠 제안·QA·테스트
- UT: Unity·서브컬처·UX·상태/예외
- 리듬게임: 신규 개발·PM·스테이지 난이도
- VN: 데이터 구조·엔진 적용·오류 검수

다루지 않을 것:

- 본인이 담당하지 않은 시스템·콘텐츠
- 구현되지 않은 개인 확장안
- 정량 기록이 없는 테스트의 효과 수치
- AI 생성 코드를 독립 개발 역량으로 표현하는 문구

### 프로젝트 B — 신규 개인작

기존 프로젝트에서 비어 있는 것만 증명한다.

- 선택 간 가치 비교가 보이는 밸런스
- 트렌드 분석
- 동일 기준의 플레이테스트와 수정 전후
- 개인이 처음부터 끝까지 소유한 기획

두 프로젝트를 합치면 다음 문장이 성립해야 한다.

> 협업 프로젝트에서 로그라이트 시스템·Unity·콘텐츠·QA를 경험했고, 개인 프로젝트에서는 하나의 로그라이크 콘텐츠를 트렌드 분석·밸런스·데이터·동일 지표 테스트까지 완결했다.

## 4. 최소 고효율 개인작

### 제목

**프리즘 리콜**

### 한 줄 설명

근접과 궁수의 행동 후보를 한 번 탭해 결정 외피의 넓이와 깊이를 공략하고, 4라운드 동안 두 캐릭터의 전투 능력을 조합하는 서브컬처 하이브리드 캐주얼 로그라이크 프로토타입.

### 이 콘셉트를 선택하는 이유

- 사용자가 자주 플레이한 `Jelly Busters`의 색 식별·표면 제거를 결정판의 기본 정보로 사용한다.
- 규칙을 `넓은 덩어리는 근접으로 베고, 두꺼운 결정은 궁수로 관통한다`는 한 문장으로 설명할 수 있다.
- 공격 위치가 표시된 후보 하나를 탭하는 방식으로 모바일 캐주얼의 낮은 조작 부담을 유지한다.
- 결정 외피 제거 자체를 공격으로 표현해 별도의 전투 화면이나 조작을 추가하지 않는다.
- 근접과 궁수를 교대하면 연계 공격이 열려 캐릭터 비주얼과 시스템 판단이 연결된다.
- 근접 범위·궁수 관통·연계 주기 중 무엇을 강화할지가 로그라이크 빌드 선택이 된다.
- 4라운드 블록 안에서 `학습→능력 획득→응용→종합 검증`을 완결한다.
- 3D 구현이나 몬스터 AI 없이도 시스템·콘텐츠·밸런스 데이터를 설계하고 테스트할 수 있다.
- Project TTT의 로그라이크·캐주얼·서브컬처 요구에 직접 대응하면서 특정 게임의 탑 구조를 복제하지 않는다.

## 6. 현재 구현 규칙

### 결정판과 행동 후보

- 결정판은 `5×5`셀이다. 각 셀은 1~4층의 색 결정을 가진다.
- 셀에서 현재 가장 위에 있는 색만 노출된다.
- 상하좌우로 붙어 있는 같은 색 표면은 하나의 연결 덩어리로 판정한다.
- 하단에는 현재 판에서 실행할 수 있는 행동 후보 3개가 표시된다.
- 판의 `1·2·3` 번호와 하단 후보 번호가 각 행동의 공격 위치를 연결한다.
- 근접 공격은 지정된 연결 덩어리 전체를 1층씩 제거한다.
- 궁수 공격은 지정된 결정 한 칸을 기본 2층 관통한다.
- 후보가 공격 위치를 미리 결정하므로 플레이어는 추가 위치 선택 없이 후보 하나만 탭한다.

### 교대와 연계

- 근접 다음 궁수 또는 궁수 다음 근접을 사용하면 연계 게이지가 1칸 증가한다.
- 같은 캐릭터를 연속 사용해도 기존 연계 게이지는 감소하지 않는다.
- 기본 3회의 교대가 누적되면 세 번째 행동 후보가 연계 공격으로 교체된다.
- 연계 공격은 지정된 연결 덩어리 표면을 제거한 뒤 중심 결정에 2층 관통 피해를 추가한다.
- 연계 공격 사용 후 연계 게이지와 마지막 사용 캐릭터 정보가 초기화된다.

### 반격과 실패

- 시작 보호막은 3칸이며 네 라운드 동안 유지된다.
- 행동 후보를 한 번 사용할 때마다 반격 게이지가 1칸 증가한다.
- R1·R2는 6탭, R3·R4는 5탭에 반격이 발생해 보호막이 1칸 감소한다.
- 반격 기준을 채운 마지막 탭으로 모든 결정을 제거했다면 반격은 취소된다.
- 결정이 남은 상태에서 보호막이 0이 되면 블록 실패다.
- 보호막 회복은 현재 프로토타입에 구현하지 않았다.

### 능력

| 능력 | 실제 구현 효과 |
|---|---|
| 회전 베기 | Lv.1은 근접 공격 덩어리의 상하좌우, Lv.2는 대각선까지 주변 표면을 추가 파괴 |
| 관통 화살 | 궁수 공격의 관통 깊이가 기본 2층에서 레벨마다 1층 증가 |
| 교차 사격 | 연계 공격에 필요한 교대 횟수가 기본 3회에서 레벨마다 1회 감소 |

- R1·R3 종료 후 근접·궁수·연계 능력 3개가 항상 모두 제시된다.
- 각 능력은 `근접 강화·궁수 강화·연계 강화` 역할표를 사용한다.
- 이미 가진 능력을 다시 고르면 최대 2레벨까지 강화된다.
- 능력과 캐릭터별 사용 횟수는 네 라운드 동안 유지된다.

### 4라운드 고정 흐름

```text
R1: 근접·궁수 교대 온보딩, 반격 6탭
→ 능력 3택
R2: 3색·공격 위치 판단, 반격 6탭
→ 다음 라운드 예고
R3: 작은 덩어리·연계 압박형, 반격 5탭
→ 능력 3택
R4: 최대 4층·빌드 종합 검증, 반격 5탭
→ 결과 등급·재시작
```

- 네 라운드의 결정 배치와 순서는 현재 고정이다.
- R1·R3에서는 능력 선택 화면, R2에서는 다음 라운드 예고 화면, R4에서는 결과 화면을 표시한다.
- 결과 화면에는 누적 사용량이 높은 주력 전술, 총 탭 수, 잔여 보호막, 근접·궁수·연계 사용 횟수를 표시한다.
- 등급은 `S: 보호막 3·24탭 이하`, `A: 보호막 2 이상·30탭 이하`, `B: 보호막 1 이상`, `C: 그 외` 조건으로 계산한다.
- 실패 시 도달 라운드와 총 탭 수를 보여주고 처음부터 다시 시작한다.

### UI·피드백

- 모바일 세로 화면을 기준으로 라운드 트랙, 보호막, 반격·연계 게이지, 결정판, 보유 능력, 행동 후보를 한 화면에 배치한다.
- 색상만으로 구분하지 않도록 `적색 ◆·청색 ●·황색 ▲` 기호를 함께 사용한다.
- 결정에는 현재 색, 남은 층 수, 후보와 연결되는 목표 번호를 표시한다.
- 행동 후보에는 캐릭터 역할, 공격 방식, 대상 색, 예상 제거 범위를 함께 표시한다.
- 마우스·키보드 포커스 시 해당 후보가 공격할 결정이 강조된다.
- 유효 공격에는 화면 플래시, 제거 개수, 추가 타격 또는 관통 깊이 문구를 제공한다.
- 보유 능력은 역할·이름·레벨 칩으로 표시한다.
- 시작 안내, 게임 방법, 능력 선택, 다음 라운드 예고, 성공 결과, 실패 결과를 모달 화면으로 구현했다.
- 캐릭터·결정·광원은 외부 리소스 없이 CSS 더미 그래픽으로 표현했다.

### 핵심 판단

> 넓은 덩어리를 근접으로 제거할 것인가, 두꺼운 결정을 궁수로 열어 다음 연결을 만들 것인가, 교대 공격으로 연계를 준비할 것인가?

### 미구현 확장안

8라운드형은 현재 4라운드 블록을 두 번 연결하는 안이며 구현되지 않았다. 라운드 무작위화, 블록 사이 회복, 능력 6종 확장, 영구 성장과 경제 역시 현재 구현 범위가 아니다.

이 한 질문이 시스템·콘텐츠·밸런스를 관통해야 한다.

## 9. 가장 빠른 테스트 방식

현재 검증 대상은 외부 리소스 없이 제작한 로컬 HTML 프로토타입이다.

### 테스트 질문

1. 첫 행동에서 근접과 궁수 중 무엇을 선택했고 그 이유는 무엇인가
2. 즉시 제거량과 아래층 색 개방 중 무엇을 우선했는가
3. 판의 번호와 행동 후보의 공격 위치 관계를 설명 없이 이해했는가
4. 교대 공격이 연계 후보를 만든다는 사실을 인식했는가
5. 다시 플레이한다면 근접·궁수·연계 중 다른 능력을 선택하고 싶은가

### 최소 측정값

- 캐릭터별 첫 선택률
- 후보 번호와 공격 위치를 잘못 연결한 횟수
- 라운드별 평균 탭 수
- 라운드별 피격 횟수와 잔여 보호막
- 연계 공격 사용 횟수와 준비 후 미사용 횟수
- 능력별 선택률
- 4라운드 도달률과 완료 시간
- 규칙 오해 횟수
- 재플레이 의향 5점 척도

테스트 결과가 없으면 결과 수치를 만들지 말고 `테스트 계획`이라고 명시한다.
