## 3. 플로어 종료 규칙

- 일반 플로어는 룬 4개를 모두 사용하면 적이 남아 있어도 클리어한다.
- 룬 4개를 사용하기 전에 모든 적을 처치하면 즉시 클리어한다.
- 보스가 쓰러지면 일반 몬스터가 남아 있어도 즉시 보스 플로어를 클리어한다.
- 보스 외 일반 몬스터가 남으면 플로어 전멸 보상은 지급하지 않는다.
- 네 번째 룬 처리 후 보스가 살아 있으면 보스전 실패다.

### 일반 몬스터 이동 연동

- 턴 시작 시 각 몬스터의 다음 목적지를 인접 8칸에서 미리 정한다.
- 보드 밖·기존 룬 흔적·오염·다른 몬스터의 현재 칸·이미 예약된 목적지는 후보에서 제외한다.
- 목적지가 없으면 정지한다.
- 화살표는 몬스터 몸체 안이 아니라 현재 칸과 목적지 칸 사이에 표시한다.
- 새 룬이 목적지를 막으면 재탐색하지 않고 정지한다.
- 유혹이 적용될 때만 새 룬으로 돌진해 피격된다.
- 되돌리기·플로어 초기화·강제 종료 복귀로 목적지를 재추첨하지 않는다.

## 4. 피격과 방어막

모든 적에게 같은 로직을 사용한다.

```text
피격 대상의 방어막 > 0 → 방어막 1 감소, 생존
피격 대상의 방어막 = 0 → 본체 사망
```

- 별도의 체력 수치는 사용하지 않는다.
- 일반 몬스터의 초기 방어막은 0이다.
- 한 대상은 한 번의 룬 행동에서 최대 1회만 피격된다.
- 이미 피격된 대상은 같은 룬 행동의 뒤 능력 대상에서 제외한다.
- 직접 룬 경로가 방어막 없는 본체를 처치했을 때만 EXP 1을 지급한다.
- 직접 공격의 방어막 파괴, 끝점 참격, 유혹, 도탄에 의한 처치는 EXP를 지급하지 않는다.
- 체력 바 대신 방어막 아이콘과 본체 상태를 표시한다.

필요 상태 예시:

- `shieldCount`
- `hitResolvedThisAction`
- `isDead`

`hitResolvedThisAction`은 다음 룬 행동 시작 시 초기화한다.

## 5. 전투 처리 순서

1. 직접 룬 경로 피격·처치 및 직접 처치 수 계산
2. 끝점 참격
3. 유혹 충돌
4. 도탄
5. 생존 몬스터와 보스 이동 및 오염
6. 예약된 증원 소환
7. 전멸·보스 처치·플로어 클리어 판정
8. 상태 저장
9. 대기 중인 레벨업 선택

- 능력 피격은 다른 능력의 발동 조건을 만들지 않는다.
- 계산·미리보기·실제 처리에서 동일한 순서를 사용한다.
- 두 효과가 같은 대상을 가리키면 먼저 처리되는 효과만 피격시키고 뒤 효과는 다른 유효 대상을 찾거나 적용되지 않는다.

## 6. 전투 능력

### 6.1 유혹

- 직접 공격과 끝점 참격에서 살아남고 아직 피격되지 않은 대상 중 이동 예정 칸이 새 룬에 막힌 대상을 판정한다.
- 기본 이동에서는 정지할 상황이지만 유혹 대상은 새 룬으로 돌진해 1회 피격된다.
- 이동형 보스도 대상에 포함한다.

| 단계 | 유효 대상 |
|---|---|
| 1 | 우선순위 1마리 |
| 2 | 우선순위 2마리 |
| 3 | 모든 유효 대상 |

우선순위:

1. 룬 시작점에서 끝점 순서로 이동 예정 칸이 막히는 위치를 비교한다.
2. 같은 순번이면 화면 기준 왼쪽을 우선한다.
3. 좌우 위치도 같으면 룬 진행 방향 쪽을 우선한다.
4. 완전히 수평인 진행은 위쪽을 우선한다.

### 6.2 도탄

- 한 룬으로 방어막 없는 일반 몬스터를 2마리 이상 직접 처치하면 발동한다.
- 플로어당 최초 조건 충족 시 1회만 자동 발동한다.
- 보스는 대상이 아니다.
- 아직 피격되지 않은 일반 몬스터를 룬 끝점과 가까운 순서로 선택한다.
- 거리는 칸 중심의 직선거리로 비교하며 구현에서는 `dx² + dy²`를 사용할 수 있다.
- 동률이면 화면 위쪽, 세로 위치도 같으면 왼쪽을 우선한다.

| 단계 | 추가 피격 대상 |
|---|---:|
| 1 | 1마리 |
| 2 | 2마리 |
| 3 | 3마리 |

- 남은 대상이 단계 수보다 적으면 남은 대상 모두를 한 번씩 피격시킨다.
- 방어막 보유 일반 몬스터가 추후 추가되면 도탄은 본체를 즉사시키지 않고 방어막 1개만 파괴한다.

### 6.3 끝점 참격

- 룬 끝점과 마지막 진행 방향을 기준으로 추가 범위를 공격한다.
- 추가 공격은 룬 흔적을 남기지 않는다.
- 보드 밖 범위는 보정하지 않고 소멸한다.

| 단계 | 범위 |
|---|---|
| 1 | 마지막 진행 방향 앞쪽 1칸 |
| 2 | 전방 3칸 |
| 3 | 끝점 주변 8칸에서 직전 룬 칸을 제외한 7칸 |

- 직교 방향 2단계는 전방 중앙과 좌우 한 칸이다.
- 우상향 대각선 예시는 위·우상단·오른쪽 3칸이다.
- 다른 대각선은 같은 형태를 회전해 사용한다.
- 유효한 끝점이 생긴 순간부터 범위 테두리와 피격 결과를 표시한다.

## 7. 퍼즐 능력 — 임시 기본값

`v0.1.0`에서는 모두 최대 단계 1로 취급하고 획득 후 카드 출현 목록에서 제외한다. 최종 성장 구조는 플레이 테스트 후 결정한다.

### 7.1 오염 무시

- 플로어당 1회
- 한 룬이 오염 칸 1개를 통과할 수 있다.
- 통과한 오염은 제거되지 않는다.
- 오염 칸은 룬 형태 판정에는 포함하지만 그 칸에 새 흔적을 남기지 않는다.
- 실제로 오염을 통과한 룬을 정상 완성했을 때 사용 처리한다.

### 7.2 룬 연결

- 플로어당 1회
- 기존 룬 흔적의 양 끝점을 발광시킨다.
- 끝점에서 새 룬을 시작하면 공유 칸을 새 룬의 첫 칸으로 인정한다.
- 새 룬을 완성하면 연결된 이전 룬 흔적 전체를 제거한다.
- 공유 끝점은 새 룬 흔적으로 유지한다.
- 완성 전에 제거될 이전 흔적을 낮은 알파값으로 표시한다.
- 취소·인식 실패 시 사용하지 않는다.

### 7.3 룬 교체

- 플로어당 1회
- 남은 룬 하나를 선택해 다른 기본 형태의 룬으로 무작위 교체한다.
- 회전·반전만 다른 형태는 같은 기본 룬으로 취급한다.
- 현재 보드에서 합법적인 배치가 있는 룬을 보장하지 않는다.
- 교체 확정 시 사용 처리한다.
- 되돌리기·초기화·강제 종료로 결과를 재추첨하지 않는다.

## 8. 능력 카드

- 현재 출현 가능한 모든 카드는 같은 확률을 가진다.
- 계열별 출현 보장은 두지 않는다.
- 최대 단계 능력은 출현 목록에서 제외한다.
- 후보가 3개 이상이면 중복 없이 3개를 표시한다.
- 후보가 1~2개면 남은 카드만 표시한다.
- 후보가 0개면 해당 레벨업 대신 아웃게임 재화를 지급한다.
- 정확한 재화량은 미정이다.
- 혼합 빌드를 허용하며 밸런스는 플레이 테스트 후 조정한다.

## 9. 이동형 보스

### 초기 배치값

| 구간 | 방어막 | 본체 포함 필요 피격 | 일반 몬스터 |
|---|---:|---:|---:|
| 스테이지 1 | 1 | 2 | 3 |
| 스테이지 2 | 1 | 2 | 3 |
| 스테이지 3 | 2 | 3 | 5 |

### 이동

- 보스가 일반 몬스터보다 먼저 인접 8칸의 목적지를 예약한다.
- 보드 밖·기존 흔적·오염·다른 적의 현재 칸은 제외한다.
- 일반 몬스터는 보스 현재 칸과 목적지를 예약할 수 없다.
- 목적지가 없으면 정지한다.
- 보스 화살표는 현재 칸과 목적지 칸 사이에 일반 몬스터와 구분되게 표시한다.
- 룬 처리가 끝난 뒤 살아 있는 보스는 피격 여부와 관계없이 예약 목적지로 이동한다.
- 새 룬이 목적지를 막으면 유혹이 없을 때 정지한다.
- 유혹이 있으면 충돌 피격을 시도하지만 이미 해당 룬 행동에서 피격됐다면 추가 방어막을 잃지 않는다.
- 직접 공격을 받고 살아남아 흔적 위에 서더라도 다음 턴에는 흔적 밖으로 이동할 수 있다.
- 첫 위치와 이동 목적지는 남은 룬 중 하나 이상으로 유효 피격이 가능한 상태만 허용한다.

## 10. 보스 변형

### 10.1 증폭 방어막

- 기본 방어막에 1개를 추가한다.
- 최종 방어막과 총 필요 피격 수를 스테이지 진입 시 공개한다.
- `v0.1.0`에서는 스테이지 1·2에만 허용하고 스테이지 3에는 적용하지 않는다.

### 10.2 증원 소환

- 보스가 피격 후 생존하면 일반 몬스터 1마리 소환을 예약한다.
- 보스 본체가 죽은 피격에서는 발동하지 않는다.
- 한 룬 행동에서 최대 1마리다.
- 기존 적 이동이 끝난 뒤 보스의 최종 위치에 인접한 합법적인 8칸 중 하나를 무작위로 선택한다.
- 보드 밖·룬 흔적·오염·다른 적이 있는 칸은 제외한다.
- 후보가 없으면 소환하지 않는다.
- 룬 확정 전에 유령 몬스터로 예상 소환 칸을 표시한다.
- 무작위 상태를 고정해 미리보기·취소·되돌리기·복귀로 재추첨하지 않는다.
- 소환된 몬스터는 방어막이 없고 해당 턴에는 이동하거나 오염을 만들지 않는다.

## 11. 보스 정보 공개

- 스테이지 진입 시 보스 유형, 총 필요 피격 수, 이동 방식, 변형 이름·조건·수치를 공개한다.
- 보스 플로어 진입 시 같은 정보를 다시 표시한다.
- 스테이지 진행 중 다시 볼 수 있는 정보 버튼을 제공한다.
- 강제 종료와 복귀로 보스·변형을 바꾸지 않는다.
- 챕터 전체 재도전에서만 새 조합을 생성한다.

## 12. 저장해야 할 신규 상태

- 능력 보유 여부와 전투 능력 단계
- 퍼즐 능력의 플로어당 사용 여부
- 도탄의 플로어당 발동 여부
- 대상별 방어막 수와 사망 상태
- 몬스터와 보스의 현재 위치·예약 목적지
- 보스 유형·변형·현재 방어막
- 증원 소환 예약과 무작위 상태
- 룬 교체 결과와 무작위 상태
- 능력 카드 후보와 미선택 레벨업

되돌리기·플로어 초기화·강제 종료 복귀로 무작위 결과를 유리하게 다시 추첨할 수 없어야 한다.

## 13. 개발자가 추정한 내용 기록

- 기획서에 없는 동작을 추정해 구현했다면 업데이트 문서에 `임의 구현·추정` 섹션을 별도로 둔다.
- 각 항목에 `추정한 내용`, `추정 이유`, `기획 확인 필요 여부`를 기록한다.
- 추정값을 확정 기획처럼 본문에 섞지 않는다.

## 14. 검증 항목

- 한 대상이 같은 룬 행동에서 두 번 피격되지 않는가.
- 방어막 파괴와 본체 사망이 같은 공통 로직으로 처리되는가.
- 직접 본체 처치만 EXP를 지급하는가.
- 전투 능력 처리 순서와 미리보기 결과가 일치하는가.
- 도탄이 보스를 선택하지 않고 거리·동률 규칙을 지키는가.
- 직교·대각선 끝점 참격 범위가 회전해도 일관적인가.
- 퍼즐 능력 사용 횟수와 취소·실패 시 소비 여부가 정확한가.
- 룬 연결 후 이전 흔적과 공유 끝점 상태가 정확한가.
- 이동형 보스가 공격 불가능한 위치를 선택하지 않는가.
- 증원 소환이 인접 합법 칸만 사용하고 해당 턴에 행동하지 않는가.
- 저장·복귀·되돌리기로 이동·소환·교체·카드 결과를 재추첨할 수 없는가.
- 보스와 변형 정보가 스테이지 진입 시 공개되고 다시 열 수 있는가.

## 15. 임시값과 미확정

- EXP 7, 보스 플로어 일반 몬스터 3·3·5는 초기 테스트값이다.

- 플로어 전멸 재화량과 반복 파밍 방지는 미확정이다.
- 순수 전투·순수 퍼즐·혼합 빌드의 최종 밸런스는 미확정이다.
