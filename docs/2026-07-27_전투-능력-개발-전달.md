## 1. 공통 구현 규칙 — 확정

- 전투 능력은 같은 능력을 다시 선택하면 강화되며 최대 3단계다.
- 직접 처치는 새로 완성한 룬 경로가 통과한 몬스터만 뜻한다.
- 능력으로 추가 처치한 몬스터는 EXP를 주지 않는다.
- 추가 처치는 플로어 전멸 판정에는 포함한다.
- 능력 처치는 다른 능력의 조건을 충족시키거나 연쇄 발동시키지 않는다.
- 룬을 확정하기 전에 직접 처치와 능력 추가 처치 결과를 미리 계산한다.
- 처치 예정 몬스터는 프로토타입에서 알파값을 낮춰 표시한다.
- 실제 리소스 단계에서는 처치 예정 아이콘을 추가한다.

## 2. 유혹 — 확정

### 발동

- 직접 룬 공격에서 생존한 몬스터 중 이동 예정 칸이 이번 턴의 새 룬에 막힌 몬스터를 대상으로 한다.
- 기본 이동 규칙에서는 정지할 상황이지만, 유혹 대상은 새 룬으로 돌진해 추가 처치된다.

### 성장

| 단계 | 효과 |
|---|---|
| 1 | 우선순위가 가장 높은 유효 대상 1마리 |
| 2 | 우선순위가 높은 유효 대상 2마리 |
| 3 | 모든 유효 대상 |

### 대상 우선순위

1. 룬의 시작점에서 끝점 방향으로 새 흔적을 순회한다.
2. 이동 예정 칸이 먼저 막히는 몬스터를 우선한다.
3. 같은 순번이면 화면 기준 왼쪽 몬스터를 우선한다.
4. 좌우 위치도 같으면 룬 진행 방향 쪽을 우선한다.
5. 완전히 수평인 룬에서는 위쪽 몬스터를 우선한다.

### 표시

- 룬 확정 전에 유혹으로 처치될 몬스터를 미리 표시한다.
- 대상이 바뀌면 표시도 실시간으로 갱신한다.

## 3. 추가 처치 능력 — 일부 확정

- 정식 명칭은 미정이다. 개발 표기는 임시로 `연속 격파`를 사용할 수 있다.
- 한 번의 룬으로 일반 몬스터를 2마리 이상 직접 처치하면 발동한다.
- 한 플로어에서 최초 조건 충족 시 1회만 자동 발동한다.
- 플로어가 바뀌면 발동 가능 상태를 회복한다.
- 보스에게는 적용하지 않는다.
- 룬 끝점에서 가까운 일반 몬스터부터 단계 수만큼 선택한다.
- 거리는 칸 중심 사이의 직선거리로 비교한다. 구현에서는 `dx² + dy²` 비교로 제곱근 계산을 생략할 수 있다.
- 거리가 같으면 화면 위쪽을 먼저, 세로 위치도 같으면 왼쪽을 먼저 선택한다.

| 단계 | 추가 처치 |
|---|---:|
| 1 | 일반 몬스터 1마리 |
| 2 | 일반 몬스터 2마리 |
| 3 | 일반 몬스터 3마리 |

### 구현 보류

- 남은 일반 몬스터가 단계 수보다 적거나 0마리일 때 발동권을 소비하는지도 미확정이다.
- 위 규칙은 개발자가 임의로 결정하지 말고 기획 확정 후 구현한다.

## 4. 끝점 참격 — 일부 확정

### 성장

| 단계 | 추가 공격 범위 |
|---|---|
| 1 | 끝점 진행 방향 앞쪽 1칸 |
| 2 | 진행 방향 앞쪽 3칸 폭 |
| 3 | 끝점 중심 3×3에서 끝점과 직전 룬 칸을 제외한 7칸 |

### 공통

- 공격 중심은 룬의 끝점이다.
- 추가 공격은 룬 흔적을 남기지 않는다.
- 보드 밖 공격 칸은 보정하지 않고 소멸한다.
- 여러 공격 칸이 같은 보스와 겹쳐도 보스에는 최대 1회의 유효 타격만 적용한다.
- 유효한 끝점이 정해진 순간부터 룬 확정 전까지 공격 범위를 테두리로 표시한다.
- 경로 변경·취소 시 범위와 처치 예정 표시를 즉시 갱신하거나 복원한다.

### 구현 보류

- 8방향 이동을 사용하는 보드에서 대각선으로 끝난 룬의 2단계 3칸 배치가 아직 확정되지 않았다.
- 직교 방향 범위를 먼저 독립 구현할 수는 있지만, 대각선 범위를 임의 해석해 확정 구현하지 않는다.

## 5. 복합 능력 처리 — 구현 보류

- 유혹, 추가 처치, 끝점 참격을 동시에 보유했을 때의 처리 순서가 아직 확정되지 않았다.
- 두 능력이 같은 몬스터를 대상으로 삼을 때의 중복 방지 규칙도 미확정이다.
- 각 능력의 단독 동작과 미리보기는 구현할 수 있지만 복합 발동은 기획 확정 전 임의로 연결하지 않는다.

## 6. 개발자가 추정한 내용 기록 규칙

- 기획서에 없는 동작을 추정해 구현했다면 업데이트 문서에 `임의 구현·추정` 섹션을 별도로 둔다.
- 각 항목에 `추정한 내용`, `추정 이유`, `기획 확인 필요 여부`를 기록한다.
- 추정값을 확정 기획처럼 본문에 섞지 않는다.

## 7. 프로토타입 검증 항목

- 직접 처치와 능력 추가 처치의 EXP 판정이 분리되는가.
- 능력 추가 처치가 다른 능력을 다시 발동시키지 않는가.
- 미리보기와 실제 처치 결과가 일치하는가.
- 되돌리기·플로어 초기화 후 능력 단계와 플로어당 발동 상태가 정확히 복원되는가.
- 유혹 대상 우선순위가 같은 저장 상태에서 항상 동일한가.
- 끝점 참격의 보드 밖 범위와 보스 최대 1타 규칙이 지켜지는가.
